# Agent 03: 建骨架 + 写概念笔记 + 图表

## 目的
创建H2/H3文件夹结构、MOC文件、费曼式概念笔记、添加7种图表。

## 输入
- 教科书原文/ 文件夹（64个§文件）
- templates/ 模板
- 用户指定的笔记级别

## 输出
- H2文件夹 + H3子文件夹 + MOC文件
- 所有原子笔记（空.md + 后续填充）
- 费曼式概念笔记（含类比 + 公式 + 推导 + 误区 + 检验）
- Mermaid/PlantUML/WaveDrom/Graphviz/Vega-Lite 图表

## 步骤
1. 读教科书原文/ 分析章§结构
2. 为每章创建H2文件夹
3. 为每节创建H3子文件夹 + MOC.md
4. 为每节创建原子笔记
5. 费曼填充：逐§读取原文 → 写概念笔记
   - ★级：定义+类比+公式+推导+3题检验
   - ★★级：★级 + 预习板块 + 例题 + MATLAB提示词
   - ★★★级：★★级 + 完整推导链 + 工程应用 + 6题检验
6. 添加图表：根据内容选Mermaid/PlantUML/WaveDrom/Graphviz/Vega-Lite
7. 添加 [[Wiki链接]] 概念导航
8. 添加 `**关键词**` RAG标签

## 每个笔记的最终结构
```markdown
**关键词**: 具体标签
## 教科书原文 → [[§链接]]
## 概念定义（费曼第1步）
## 类比与直觉（费曼第2步）
## 核心公式详释（$$ + 符号表）
## 推导脉络（图表）
## 常见误区（费曼第3步）
## 费曼检验（费曼第4步）
## 概念导航
## 自己理解
```
