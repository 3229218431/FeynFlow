# Agent 03: 构建知识库

## 任务
创建 H2/H3 文件夹骨架、MOC 文件、费曼式概念笔记、添加7种图表。

## 步骤

### 第1步：读取教科书原文目录
读取 `教科书原文/` 下的所有章§文件 → 建立章节结构清单。

### 第2步：创建文件夹结构
为每章创建 H2 文件夹，为每节创建 H3 子文件夹：
```
第X章 标题/
  本节标题/
    主题名 MOC.md（章节导航索引）
    概念名.md（费曼式概念笔记）
    习题.md（课后习题）
```

### 第3步：填充 MOC 索引
为每个 H3 创建 MOC.md，包含：
- 学习状态勾选框 `- [ ]`
- 所有原子笔记的 Wiki 链接
- 概念导航（前置/后续/关联）

### 第4步：费曼式填充核心笔记
逐节读取 `教科书原文/` 中的原文，按指定级别填充：

**★ 基础级**（3000-6000B）：
```
**关键词**：标签
## 教科书原文 → [[§链接]]
## 概念定义（费曼第1步：一句话）
## 类比与直觉（费曼第2步：2-3个生活比喻）
## 核心公式详释（$$ + 符号表）
## 推导脉络（Mermaid flowchart/其他图表）
## 常见误区（费曼第3步）
## 费曼检验（费曼第4步：2-3题）
## 概念导航（[[双向链接]]）
## 自己理解
```

**★★ 进阶级**（6000-10000B）：★全部 + 预习板块 + 教科书推导 + 例题 + MATLAB提示词

**★★★ 精通级**（10000-15000B）：★★全部 + 完整推导链 + 工程应用 + 跨章关联 + 6题检验

### 第5步：添加图表
根据内容选择适当图表工具嵌入笔记（作为 ```代码块 直接写在笔记中）：
- 推导流程 → Mermaid flowchart
- 对比分类 → PlantUML classDiagram
- 时域波形 → WaveDrom JSON
- 概念关系 → Graphviz DOT
- 场分布 → Vega-Lite JSON

### 第6步：添加双向链接
- 每篇笔记的「概念导航」置前/后/关联各 ≥1 个 `[[链接]]`
- 总览文件引用所有 MOC
- 确保无孤立节点
