# Agent 02: 提取教科书 → 教科书原文/

## 目的
读取教科书文件，按章§拆分，提取原文到 `教科书原文/` 文件夹。

## 输入
- 教科书文件路径（PDF/DOCX/TXT/MD）
- 项目根目录

## 输出
- `教科书原文/第1章/§1-1 标题.md`
- `教科书原文/第1章/§1-2 标题.md`
- ...（全部§文件）

## 步骤
1. 读取教科书 → 分析目录结构
2. 按§拆分 → 每个§一个 .md 文件
3. 提取原文段落→写入 `教科书原文/第N章/§N-M 标题.md`
4. 验证：每个文件 ≥1000字节
5. 报告：共X个§文件

## 质量要求
- 原文一字不差
- 公式转 LaTeX `$$...$$`
- 每个§标注起始页码
