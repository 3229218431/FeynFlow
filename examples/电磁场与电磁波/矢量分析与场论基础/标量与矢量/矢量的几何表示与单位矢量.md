# 矢量的几何表示与单位矢量
**关键词**：标量与矢量

📌 **一句话本质**：单位矢量就是"只有方向没有长短"的箭头——它像一个方向指示牌，任何矢量都可以写成"大小 × 方向牌"。

🏷️ **重要度**：🟡 | 考试：★★ | 题型：选

🔧 **工程/实际场景**：天线辐射方向图——天线在空间各方向的增益用球坐标单位矢量 (\hat{r}, \hat{\theta}, \hat{\phi}) 分解。如果单位矢量方向定义混乱（比如\hat{\theta}取反），天线方向图的增益最大值方向会偏离设计目标，导致通信盲区。

## 🧠 类比与直觉

单位矢量就像一个"方向标签"——把任意箭头（矢量）除以自己的长度，就得到这个纯方向标签。它不关心你走多远，只管你朝哪走。就像指南针：不管你是走10米还是10公里，北方的方向不变。矢量 = 步长（模）x 方向牌（单位矢量）。

**口诀**："单位矢量指向牌，模长为一方向在"

## 在电磁场中的重要应用

### 1. 电场方向的表示
点电荷电场: $$\mathbf{E} = \frac{q}{4\pi\varepsilon_0 r^2}\hat{r}$$
其中 $$\hat{r}$$ 是从电荷指向观察点的径向单位矢量。这里的单位矢量方向随观察点位置变化（球坐标）。

### 2. 坡印亭矢量方向
$$\mathbf{S} = \mathbf{E} \times \mathbf{H}$$
单位矢量 $$\hat{s} = \hat{e} \times \hat{h}$$ 指示能流方向——右手定则。

### 3. 面元方向的表示
高斯定律中: $$d\mathbf{S} = \hat{n}\,dS$$ 其中 $$\hat{n}$$ 是闭合曲面的外法线单位矢量。正确指定 $$\hat{n}$$ 的方向是正确计算电通量的前提。

### 4. 边界条件中的方向
- 法向: $$\hat{n}$$ 从介质1指向介质2
- 切向: 垂直于 $$\hat{n}$$ 的任意方向
- 例如: $$\mathbf{n} \times (\mathbf{E}_1 - \mathbf{E}_2) = 0$$ 中的 $$\mathbf{n}$$ 是界面的法向单位矢量

## 三种坐标系单位矢量转换

**直角↔柱坐标**:
$$\hat{x} = \cos\phi\,\hat{r} - \sin\phi\,\hat{\phi}$$
$$\hat{y} = \sin\phi\,\hat{r} + \cos\phi\,\hat{\phi}$$
$$\hat{z} = \hat{z}$$

**直角↔球坐标**:
$$\hat{x} = \sin\theta\cos\phi\,\hat{r} + \cos\theta\cos\phi\,\hat{\theta} - \sin\phi\,\hat{\phi}$$
$$\hat{y} = \sin\theta\sin\phi\,\hat{r} + \cos\theta\sin\phi\,\hat{\theta} + \cos\phi\,\hat{\phi}$$
$$\hat{z} = \cos\theta\,\hat{r} - \sin\theta\,\hat{\theta}$$

## ✂️ 可跳过
- 三种坐标系单位矢量转换公式考试通常给出，不需逐字背诵
- 只需记住直角坐标单位矢量是常矢量，圆柱坐标和球坐标的单位矢量随空间点变化
