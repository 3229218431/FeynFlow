# 库仑规范与洛伦兹规范的选择
**关键词**：动态位, φ, A, 洛伦兹规范, 库仑规范, 达朗贝尔方程

## 教科书原文

> 📖 参见：[[§7-4 标量位与矢量位]]

## 概念定义（费曼第1步）
规范条件是给"不唯一确定的"矢量位 A 加上一条额外规则。选择不同的规则（库仑规范或洛伦兹规范）就像给同一个数学问题选不同的坐标系——最终答案（E 和 B）不变，但解题过程的难度天差地别。

## 类比与直觉（费曼第2步）

**类比1：给一个函数的"积分常数"下定义**
已知 $$\nabla \times A = B$$ 只能确定 A 的"旋度部分"，无法确定 A 的"散度部分"——就像已知 $$f'(x) = 2x$$ 只能确定 $$f(x) = x^2 + C$$，C 是任意常数。规范条件就像指定 C 的值（例如要求 $$f(0) = 0$$ 则 C=0）。

**类比2：GPS坐标系的"海拔零点"选择**
- A 的散度 = 海拔高度的"零点"定义
- 库仑规范 = 以海平面为零点（$$\nabla \cdot A = 0$$）
- 洛伦兹规范 = 以GPS椭球面为零点（$$\nabla \cdot A = -\mu\varepsilon\partial\Phi/\partial t$$）
- 最终计算出的山峰高度（E 和 B）在两种坐标系中是相同的

## 核心公式详释

### 规范条件对比

| 特性 | 库仑规范 | 洛伦兹规范 |
|------|----------|------------|
| 条件 | $\nabla \cdot A = 0$ | $\nabla \cdot A = -\mu\varepsilon\frac{\partial\Phi}{\partial t}$ |
| A的方程 | 含 $$\Phi$$ 耦合项 | 纯 A 方程 |
| $\Phi$$的方程 | 瞬时泊松方程 | 波动方程（有限速度） |
| 相对论协变 | 否 | 是 |
| 时变场计算 | 复杂（方程耦合） | 简单（方程解耦） |
| 静态场计算 | 简单 | 可退化 |
| 量子物理 | 常用 | 相对论QED常用 |

### 规范不变性证明
对任意的标量函数 $$\psi(r,t)$$，做规范变换：
$$A' = A + \nabla\psi$$
$$\Phi' = \Phi - \frac{\partial\psi}{\partial t}$$

验证 E 不变：
$$E' = -\frac{\partial A'}{\partial t} - \nabla\Phi' = -\frac{\partial(A + \nabla\psi)}{\partial t} - \nabla(\Phi - \frac{\partial\psi}{\partial t})$$
$$= -\frac{\partial A}{\partial t} - \nabla\Phi - \frac{\partial}{\partial t}(\nabla\psi) + \nabla(\frac{\partial\psi}{\partial t}) = -\frac{\partial A}{\partial t} - \nabla\Phi = E$$

验证 B 不变：
$$B' = \nabla \times A' = \nabla \times (A + \nabla\psi) = \nabla \times A + \nabla \times \nabla\psi = B$$

这证明：**E 和 B 在规范变换下不变——规范自由度不影响物理可观测量。**

## 如何选择规范

| 场景 | 推荐规范 | 原因 |
|------|----------|------|
| 静态电场/磁场 | 库仑规范 | 方程最简，$$\nabla \cdot A = 0$$ 自然满足 |
| 时变电磁场/电磁波 | 洛伦兹规范 | 方程解耦，符合因果律和相对论 |
| 天线辐射问题 | 洛伦兹规范 | 推迟位描述有限传播速度 |
| 原子物理/量子电动力学 | 库仑规范 | $\Phi$$ 瞬时响应简化能级计算 |
| 相对论性量子场论 | 洛伦兹规范 | 显式洛伦兹协变 |

## 常见误区

1. **误区**：库仑规范和洛伦兹规范会给出不同的 E 和 B 结果。
   **修正**：两种规范给出的 E 和 B 完全相同（规范不变性）。区别仅在于计算的复杂程度。

2. **误区**：库仑规范在时变场中完全不能用。
   **修正**：库仑规范在时变场中仍然可用——E 和 B 的结果仍然正确。只是 $$\Phi$$ 的方程是瞬时的（没有波动项），计算过程更复杂，最终 E 和 B 仍然正确。

3. **误区**：规范条件的选择是一种"假设"。
   **修正**：规范条件是数学规定（对 A 散度的约束），不是物理假设。任何合理的散度选择都是允许的，最终物理结果不变。

4. **误区**：洛伦兹规范中的 $$\nabla \cdot A \neq 0$$ 意味着 A 是有散的，违反了 $$\nabla \cdot B = 0$$。
   **修正**：A 本身可以有散度，但 B = $$\nabla \times A$$ 始终无散（旋度的散度恒为零）。A 的散度不影响 B 的无散性。

## 费曼检验

**问题1**：证明无论选择哪种规范，$$\nabla \cdot B = 0$$ 始终自动满足。
> 提示：$$B = \nabla \times A$$，$$\nabla \cdot (\nabla \times A) = 0$$

**问题2**：从洛伦兹规范出发，令 $$\partial/\partial t \to 0$$，验证它退化为库仑规范。这说明了什么？
> 提示：静态场中 $$\partial\Phi/\partial t = 0$$

**问题3**：已知某一区域中 A 和 $$\Phi$$ 满足库仑规范和洛伦兹规范。求变换函数 $$\psi$$ 使得 $$A_{Lorenz} \to A_{Coulomb}$$。
