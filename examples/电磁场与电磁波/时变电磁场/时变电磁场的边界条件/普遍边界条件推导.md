# 普遍边界条件推导
**关键词**：边界条件, D法向, E切向, ρₛ, 介质分界面

## 教科书原文

> 📖 参见：[[§7-3 时变电磁场边界条件]]

## 概念定义（费曼第1步）
边界条件告诉你电磁场在跨越两种不同材料的分界面时，哪些分量必须连续、哪些可以不连续——就像是海关过关规则：有些东西（$$E_t$$, $$B_n$$）总是畅行无阻，有些东西（$$D_n$$, $$H_t$$）可能会被"拦截"（受表面电荷或表面电流影响）。

## 类比与直觉（费曼第2步）

**类比1：高速公路收费站**
- $$E_t$$ 连续 = 所有车辆速度的切向分量不变——不能有车辆"瞬间消失"在边界上
- $$B_n$$ 连续 = 磁通量就像水流，不能"凭空消失"或"凭空出现"
- $$D_n$$ 可能不连续 = 边界上有面电荷就像收费站有"排队"——电荷密度改变了
- $$H_t$$ 可能不连续 = 边界上有面电流就像有"高速公路匝道"——电流在边界流过

**类比2：接力赛交接棒**
- $$E_t$$ 连续 = 交接棒时速度必须连续（不能瞬间变速）
- $$B_n$$ 连续 = 棒的轨迹没有断点（法向分量连续）
- $$D_n$$ 和 $$H_t$$ = 取决于交接区是否有特殊情况（有无面电荷/面电流）

## 核心公式详释

### 四条普遍边界条件

| # | 条件 | 矢量形式 | 适用范围 |
|---|------|----------|----------|
| 1 | $E_{1t} = E_{2t}$ | $e_n \times (E_2 - E_1) = 0$ | 任何边界 |
| 2 | $B_{1n} = B_{2n}$ | $e_n \cdot (B_2 - B_1) = 0$ | 任何边界 |
| 3 | $D_{2n} - D_{1n} = \rho_S$ | $e_n \cdot (D_2 - D_1) = \rho_S$ | 一般边界 |
| 4 | $H_{2t} - H_{1t} = J_S$ | $e_n \times (H_2 - H_1) = J_S$ | 一般边界 |

| 符号 | 含义 | 单位 |
|------|------|------|
| $e_n$ | 从介质1指向介质2的边界法向单位矢量 | — |
| $\rho_S$ | 边界表面自由电荷面密度 | C/m² |
| $J_S$ | 边界表面电流密度 | A/m |
| n 下标 | 法向分量 | — |
| t 下标 | 切向分量 | — |

### 对理想介质边界（$$\rho_S = 0, J_S = 0$$）
| # | 简化条件 |
|---|----------|
| 1 | $E_{1t} = E_{2t}$$ 或 $$\frac{D_{1t}}{\varepsilon_1} = \frac{D_{2t}}{\varepsilon_2}$ |
| 2 | $B_{1n} = B_{2n}$$ 或 $$\mu_1 H_{1n} = \mu_2 H_{2n}$ |
| 3 | $D_{1n} = D_{2n}$$ 或 $$\varepsilon_1 E_{1n} = \varepsilon_2 E_{2n}$ |
| 4 | $H_{1t} = H_{2t}$ |

## 推导脉络

```mermaid
flowchart TD
    A[麦克斯韦积分形式] --> B[法拉第定律<br>∮E·dl = -∫∂B/∂t·dS]
    A --> C[磁通连续性<br>∮B·dS = 0]
    A --> D[高斯定律<br>∮D·dS = q]
    A --> E[全电流定律<br>∮H·dl = ∫(J+∂D/∂t)·dS]
    B --> F[在边界上取小矩形回路<br>令宽度→0]
    C --> G[在边界上取小圆柱体<br>令高度→0]
    D --> G
    E --> F
    F --> H[E_{1t} = E_{2t}]
    E --> I[条件: ∂D/∂t有限]
    I --> J[H_{1t} = H_{2t}（无面电流时）]
    E --> K[H_{2t} - H_{1t} = J_S（有面电流时）]
    G --> L[B_{1n} = B_{2n}]
    G --> M[D_{2n} - D_{1n} = ρ_S]
```

## 常见误区

1. **误区**：时变场的边界条件与静态场完全不同。
   **修正**：只要场量的时间变化率有限，时变场的边界条件在形式上与静态场相同——因为推导过程中涉及时间导数项的面积分在矩形回路高度趋于零时趋于零。

2. **误区**：$$H_{1t} = H_{2t}$$ 在任何边界上都成立。
   **修正**：仅当边界上没有表面电流 $$J_S$$ 时成立。在理想导体表面，$$H_t$$ 不连续（$$e_n \times H = J_S$$）。

3. **误区**：边界条件的矢量形式 $$e_n \times (E_2 - E_1) = 0$$ 和标量形式 $$E_{1t} = E_{2t}$$ 含义不同。
   **修正**：两者完全等价。矢量形式更紧凑，标量形式更适合直接计算。

4. **误区**：$$B_{1n} = B_{2n}$$ 意味着 $$H_{1n} = H_{2n}$$。
   **修正**：仅在 $$\mu_1 = \mu_2$$ 时成立。一般情况下 $$\mu_1 H_{1n} = \mu_2 H_{2n}$$，H 的法向分量在边界上可以不连续。

## 费曼检验

**问题1**：两种理想介质的边界上，已知介质1一侧 $$E_1$$ 与边界法向夹角为 30°。如果 $$\varepsilon_1 = 2\varepsilon_0$$, $$\varepsilon_2 = 4\varepsilon_0$$，求介质2一侧 $$E_2$$ 与法向的夹角。
> 提示：利用 $$E_{1t} = E_{2t}$$ 和 $$D_{1n} = D_{2n}$$（$$\varepsilon_1 E_{1n} = \varepsilon_2 E_{2n}$$）

**问题2**：边界上存在面电荷 $$\rho_S$$ 时，为什么 $$D_n$$ 不连续而 $$E_t$$ 仍然连续？
> 提示：从高斯定律的积分形式出发

**问题3**：一个理想导体表面上，已知 $$H_t = 1$$ A/m，求表面电流密度 $$J_S$$ 的大小和方向。
> 提示：$$e_n \times H = J_S$$
