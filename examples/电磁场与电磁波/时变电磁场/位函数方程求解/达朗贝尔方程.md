# 达朗贝尔方程
**关键词**：位函数, 亥姆霍兹方程, 复矢量位, k²+∇²

## 教科书原文

> 📖 参见：[[§7-4 标量位与矢量位]]

## 概念定义（费曼第1步）
达朗贝尔方程是非齐次波动方程——它描述了"源（电流或电荷）如何在空间中激发出以有限速度传播的波动"。左边是波的传播（$$\nabla^2 - \mu\varepsilon\partial^2/\partial t^2$$），右边是源（J 或 $$\rho$$）。就像你往池塘扔石头（源），水面会泛起向外传播的涟漪（波动解）。

## 类比与直觉（费曼第2步）

**类比1：扬声器和声波**
- 扬声器纸盆振动 = 电流源 J / 电荷源 $$\rho$$（源项，右手边）
- 空气中的声波传播 = $$\nabla^2 A - \mu\varepsilon\partial^2 A/\partial t^2$$（波动项，左手边）
- 达朗贝尔方程 = 描述"扬声器如何产生声波"的数学关系
- $$v = 1/\sqrt{\mu\varepsilon}$$ = 声速（电磁波的"声速"就是光速）

**类比2：湖面涟漪的微分方程**
- $$\nabla^2 h - \frac{1}{v^2}\frac{\partial^2 h}{\partial t^2} = -f(r,t)$$
- 左边描述"波纹如何在湖面传播"
- 右边 $$f(r,t)$$ 描述"是什么在扰动湖面"（丢石头的位置和时间）
- 达朗贝尔方程就是这个结构：$$h \to A$$ 或 $$\Phi$$，$$v = 1/\sqrt{\mu\varepsilon}$$

## 核心公式详释

### 矢量位 A 的达朗贝尔方程
$$\nabla^2 A - \mu\varepsilon\frac{\partial^2 A}{\partial t^2} = -\mu J$$

### 标量位 $$\Phi$$ 的达朗贝尔方程
$$\nabla^2 \Phi - \mu\varepsilon\frac{\partial^2 \Phi}{\partial t^2} = -\frac{\rho}{\varepsilon}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $\nabla^2$ | 拉普拉斯算子（空间二阶导数） | 1/m² |
| $\mu\varepsilon\frac{\partial^2}{\partial t^2}$ | 达朗贝尔项（时间二阶导数） | 1/m² |
| $v = 1/\sqrt{\mu\varepsilon}$ | 波速 | m/s |
| $\mu J$ | A 的源项 | A/m² |
| $\rho/\varepsilon$ | $\Phi$$ 的源项 | V/m² |

### 在直角坐标系中的展开
A 的矢量达朗贝尔方程可分解为三个标量达朗贝尔方程：
$$\nabla^2 A_x - \mu\varepsilon\frac{\partial^2 A_x}{\partial t^2} = -\mu J_x$$
$$\nabla^2 A_y - \mu\varepsilon\frac{\partial^2 A_y}{\partial t^2} = -\mu J_y$$
$$\nabla^2 A_z - \mu\varepsilon\frac{\partial^2 A_z}{\partial t^2} = -\mu J_z$$

### 波动速度
$$v = \frac{1}{\sqrt{\mu\varepsilon}}$$

在真空中：$$c = \frac{1}{\sqrt{\mu_0\varepsilon_0}} \approx 3 \times 10^8$$ m/s

### 静态极限（$$\partial/\partial t \to 0$$）
- $$\nabla^2 A = -\mu J$$ → **矢量泊松方程**
- $$\nabla^2 \Phi = -\rho/\varepsilon$$ → **标量泊松方程**

达朗贝尔方程是泊松方程在时变场中的自然推广——多了一项 $$\mu\varepsilon\partial^2/\partial t^2$$ 描述波动传播。

## 达朗贝尔方程 vs 波动方程 vs 泊松方程

| 方程类型 | 形式 | 适用场景 |
|----------|------|----------|
| 齐次波动方程 | $\nabla^2 u - \frac{1}{v^2}\frac{\partial^2 u}{\partial t^2} = 0$ | 无源区电磁波传播 |
| 达朗贝尔方程 | $\nabla^2 u - \frac{1}{v^2}\frac{\partial^2 u}{\partial t^2} = -f$ | 有源区位函数求解 |
| 泊松方程 | $\nabla^2 u = -f$ | 静态场位函数求解 |
| 拉普拉斯方程 | $\nabla^2 u = 0$ | 无源静态场 |

## 常见误区

1. **误区**：达朗贝尔方程只是一个方程。
   **修正**：达朗贝尔方程指的是一类方程结构（$$\nabla^2 - \partial^2/v^2\partial t^2$$）。对于 A（矢量）是矢量达朗贝尔方程（可分解为3个标量方程），对于 $$\Phi$$ 是标量达朗贝尔方程。

2. **误区**：达朗贝尔方程中的 $$v = 1/\sqrt{\mu\varepsilon}$$ 在任何介质中都是光速。
   **修正**：仅在真空中 $$v = c$$。在介质中 $$v = c/\sqrt{\mu_r\varepsilon_r} < c$$。在导电介质中，等效介电常数变为复数，相速与频率有关（色散）。

3. **误区**：静态极限下 $$\partial/\partial t \to 0$$，达朗贝尔方程中的 $$\mu\varepsilon\partial^2/\partial t^2$$ 项消失是因为"波不传播了"。
   **修正**：更准确的理解是：波的传播速度有限（$$1/\sqrt{\mu\varepsilon}$$），在静态极限下传播时间可以忽略，场与源"瞬时"关联，波动方程退化为泊松方程。

4. **误区**：只要知道了 J 和 $$\rho$$ 就能直接解达朗贝尔方程。
   **修正**：J 和 $$\rho$$ 不是独立变量——它们通过电荷守恒定律 $$\nabla \cdot J = -\partial\rho/\partial t$$ 关联。洛伦兹规范保证了这组方程的自洽性。

## 费曼检验

**问题1**：验证：在真空中的静态极限下（$$\partial/\partial t = 0$$），达朗贝尔方程退化为泊松方程。此时 $$\Phi$$ 的解是什么形式？
> 提示：回忆静电学中 $$\Phi(r) = \frac{1}{4\pi\varepsilon_0}\int \frac{\rho(r')}{|r-r'|}dV'$$

**问题2**：达朗贝尔方程在直角坐标系中可以分离为几个标量方程？为什么这种分离在球坐标系中不这么简单？
> 提示：在直角坐标中 $$\nabla^2 A = e_x\nabla^2 A_x + e_y\nabla^2 A_y + e_z\nabla^2 A_z$$

**问题3**：从洛伦兹规范出发，对 A 的达朗贝尔方程取散度，结合 $$\Phi$$ 的达朗贝尔方程，验证电荷守恒定律 $$\nabla \cdot J = -\partial\rho/\partial t$$ 是自动满足的。
