# 复数表示法的引入

📌 **一句话本质**：时谐场用复数表示——把时间因子e^(jωt)提出来，只剩空间部分，计算量减半
🏷️ **重要度**：🔴 | 考试：★★★ | 题型：计

## 🔧工程场景

天线阵列设计——用复数表示法可将每根天线的幅度和相位编码为一个复数，N元阵列的干涉图样通过N个复数加法完成。

## 教科书原文

> 📖 参见：[[§7-8 时谐电磁场]]

## 概念定义（费曼第1步）
复数表示法是一种数学"快捷键"：把正弦变化的电场 $$E(t) = E_m\cos(\omega t + \psi)$$ 压缩成一个复数 $$\dot{E} = E e^{j\psi}$$（含振幅和相位），需要时再"解压"——乘上 $$e^{j\omega t}$$ 取实部。就像.zip文件：$$\dot{E}$$ 是压缩包，$$e^{j\omega t}$$ 是解压密码。

## 🧠类比与直觉（费曼第2步）

**类比1：时钟的表盘**
- 表针长度 = 振幅 $$E_m$$（永远不变的方向和长度）
- 表针的起始角度 = 相位 $$\psi$$
- 表针的旋转速度 = 角频率 $$\omega$$
- 表针在水平轴上的投影 = 瞬时值 $$E(t) = E_m\cos(\omega t + \psi)$$
- 复数表示 = 只记录"表针长度"和"初始角度"，旋转交给 $$e^{j\omega t}$$

**类比2：音乐乐谱**
- 乐谱上的音符 = 复矢量 $$\dot{E}$$（振幅=音量，音高=频率）
- 演奏 = 乘以 $$e^{j\omega t}$$（把音符变成实际的声波振动）
- 分析乐谱比分析声波波形容易得多——这就是复矢量方法的优势

🔖 **口诀**：乘e^(jωt)取实部，微分变乘jω

## 核心公式详释

### 时谐电磁场的瞬时值
$$E(r,t) = E_m(r)\cos[\omega t + \psi_e(r)]$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $E_m(r)$ | 振幅（仅为空间函数） | V/m |
| $\omega$ | 角频率 | rad/s |
| $f$ | 频率 | Hz |
| $T$ | 周期 | s |
| $\psi_e(r)$ | 初始相位（可能是空间函数） | rad |

### 复振幅（最大值）
$$\dot{E}_m(r) = E_m(r) e^{j\psi_e(r)}$$

### 复有效值
$$\dot{E}(r) = E(r) e^{j\psi_e(r)} = \frac{\dot{E}_m(r)}{\sqrt{2}}$$

### 瞬时值与复矢量的关系
$$E(r,t) = Re[\dot{E}_m(r)e^{j\omega t}] = Re[\sqrt{2}\dot{E}(r)e^{j\omega t}]$$

### 时间导数
$$\frac{\partial}{\partial t} \longleftrightarrow j\omega$$

$$\frac{\partial E(r,t)}{\partial t} = Re[j\omega\dot{E}_m(r)e^{j\omega t}]$$

## 振幅与有效值

| 表示法 | 符号 | 关系 |
|--------|------|------|
| 瞬时值 | $E(r,t)$ | $E_m\cos(\omega t+\psi)$ |
| 振幅（最大值）复矢量 | $\dot{E}_m(r)$ | $E_m e^{j\psi}$ |
| 有效值复矢量 | $\dot{E}(r)$ | $E e^{j\psi} = \dot{E}_m/\sqrt{2}$ |
| 振幅大小 | $E_m$ | $\sqrt{2}E$ |
| 有效值大小 | $E$ | $E_m/\sqrt{2}$ |

## 使用复矢量的条件

1. **所有场量和源量必须是同一频率** $$\omega$$ 的时谐函数
2. **场的方向不随时间变化**（线极化情况下自然满足）
3. **介质参数与时间无关**（线性、时不变）
4. 运算中仅涉及**线性运算**（加法、微分、积分）
   - 非线性运算（如 $$S = E \times H$$ 的瞬时功率计算）需要回到时域

## ⚠️常见误区

1. **误区**：复矢量是一个复数，所以电场可以是"复数场"。
   **修正**：真实的物理电场始终是实数——$$Re[\dot{E}e^{j\omega t}]$$。复矢量只是数学工具，"虚部"编码了相位信息。

2. **误区**：任何时变场都可以用 $$\partial/\partial t \to j\omega$$ 简化。
   **修正**：仅适用于单频时谐场。对于脉冲、方波等多频信号，需要分别处理每个频率分量（傅里叶分析），再叠加。

3. **误区**：$$e^{j\omega t}$$ 意味着电磁场在"旋转"。
   **修正**：复指数 $$e^{j\omega t} = \cos\omega t + j\sin\omega t$$ 的实部才是物理的余弦振动。数学上的"旋转"是复数平面的旋转，不是物理空间的旋转（极化旋转是另一回事）。

4. **误区**：教材中用有效值 $$\dot{E}$$ 还是最大值 $$\dot{E}_m$$ 是随意的。
   **修正**：两种表示法都常用。有效值方便功率计算（$$P = E \cdot E^*$$ 直接得平均功率），最大值方便瞬时值还原。关键是要**始终一致**——混合使用会引入 $$\sqrt{2}$$ 因子错误。

## ❓费曼检验

**问题1**：已知 $$E(t) = 100\cos(10^8\pi t + 30^\circ)$$ V/m。写出（a）复振幅 $$\dot{E}_m$$；（b）复有效值 $$\dot{E}$$。
> 提示：$$30^\circ = \pi/6$$ rad，$$e^{j\pi/6} = \sqrt{3}/2 + j/2$$

**问题2**：已知 $$\dot{E} = (3 - j4)$$ V/m（有效值），频率 50 Hz。求（a）振幅 $$E_m$$；（b）相位 $$\psi$$；（c）瞬时值 $$E(t)$$。
> 提示：$$|3-j4| = 5$$，$$\angle(3-j4) = -\arctan(4/3)$$

**问题3**：用复矢量方法计算两个同频信号的叠加：$$E_1(t) = 10\cos(\omega t)$$，$$E_2(t) = 10\cos(\omega t + 90^\circ)$$。求合成振幅和相位。
> 提示：$$\dot{E}_{1m} = 10$$，$$\dot{E}_{2m} = 10j$$，合成 $$= 10(1+j)$$
