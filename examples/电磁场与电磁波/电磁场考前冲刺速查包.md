## 🔴 口诀速记包

### 矢量分析
- 梯度: "梯度指向最陡增，方向导数最大值"
- 散度: "散度正处源发散，负处汇点来吞咽，零散度处无增减"
- 旋度: "旋度正处左旋转，右手法则定指尖，无旋必有势函数"

### 静电场
- 高斯定律: "闭合面的电通量，等于内部总电荷除以ε₀"
- 电位: "电场等于负电位梯度——E = -∇φ"
- 边界条件: "切向E连续，法向D跳变——跳变量等于面电荷"

### 恒定磁场
- 安培定律: "闭合环路的磁环量，等于穿过电流乘μ₀"
- 磁矢位: "B = ∇×A——磁通密度是无散有旋场"

### 时变电磁场
- 法拉第定律: "变的磁场生电场——∇×E = -∂B/∂t"
- 位移电流: "变的电场也生磁场——∇×H = J + ∂D/∂t"
- 坡印廷矢量: "S = E×H——功率流的方向和密度"

## ⚠️ 十大常见错误（考前必看）

1. **混淆梯度和方向导数** → 梯度是向量，方向导数是标量
2. **散度符号搞反** → 正=源（发散），负=汇（收敛）
3. **旋度是向量不是标量** → 旋度有方向（旋转轴方向）
4. **坐标系的公式混用** → 看清题目给的是什么坐标系
5. **忘记负号：E = -∇φ** → 电场指向电位降低的方向（有负号！）
6. **位移电流漏掉** → 全电流 = 传导电流 + 位移电流
7. **边界条件方向搞错** → 切向是从边界面的方向判断
8. **坡印廷矢量方向** → S = E×H，方向是能量流动方向
9. **忘记 ε₀ 和 μ₀ 的值** → ε₀≈8.85×10⁻¹² F/m, μ₀=4π×10⁻⁷ H/m
10. **波动方程的正负号** → ∇²E - με·∂²E/∂t² = 0（负号！）
