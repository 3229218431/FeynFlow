1-4标量场的方向导数与梯度
标量场中各点标量的大小可能不等，因此某点标量沿着各个方向的变化率可能不同。为了描述标量场的这种变化特性，通常引入方向导数的概念。标量场在某点的方向导数表示标量场自该点沿某一方向上的变化率。
如图1-4-1所示，标量场 φ 在P 点沿l方向上的方向导数
$\frac{\partial\Phi}{\partial l} \mid_{P}$定义为![](media/image7.jpeg){width="1.5277777777777777in"
height="1.2777777777777777in"}
$\frac{\partial\Phi}{\partial l} \mid_{p} = \lim_{\Delta l \rightarrow 0}\frac{\Phi\left( P' \right) - \Phi(P)}{\Delta l}$
(1-4-1)
式中，Δl为P点与 P\'点之间的距离。
在直角坐标系中，方向导数 $\frac{\partial\Phi}{\partial l}$可写为
$\frac{\partial\Phi}{\partial l} = \frac{\partial\Phi}{\partial x}\frac{\partial x}{\partial l} + \frac{\partial\Phi}{\partial y}\frac{\partial y}{\partial l} + \frac{\partial\Phi}{\partial z}\frac{\partial z}{\partial l}$
若矢量l的方向余弦为cosα,cosβ,cosγ,则上式变为
$\frac{\partial\Phi}{\partial l} = \frac{\partial\Phi}{\partial x}\cos\alpha + \frac{\partial\Phi}{\partial y}\cos\beta + \frac{\partial\Phi}{\partial z}\cos\gamma$
(1-4-2)
若令
$\left( \frac{\partial\Phi}{\partial x},\frac{\partial\Phi}{\partial y},\frac{\partial\Phi}{\partial z} \right)$为矢量G
的三个坐标分量，即
$G = e_{x}\frac{\partial\Phi}{\partial x} + e_{y}\frac{\partial\Phi}{\partial y} + e_{z}\frac{\partial\Phi}{\partial z}$
(1-4-3)
而矢量l的单位矢量e₁为
$e_{1} = e_{x}\cos\alpha + e_{y}\cos\beta + e_{z}\cos\gamma$
那么，标量场φ沿矢量l方向上的方向导数
$\frac{\partial\Phi}{\partial l}$可以写为
$\frac{\partial\Phi}{\partial l} = G \cdot e_{1}$ (1-4-4)
矢量G称为标量场φ的梯度，以 gradφ表示，即
$grad\Phi = e_{x}\frac{\partial\Phi}{\partial x} + e_{y}\frac{\partial\Phi}{\partial y} + e_{z}\frac{\partial\Phi}{\partial z}$
(1-4-5)
由此可见，标量场φ的梯度是一个矢量场。由式(1-4-4)可见，当e₁的方向与梯度方向一致时，方向导数
$\frac{\partial\Phi}{\partial l}$取得最大值。因此，标量场在某点梯度的大小等于该点的最大方向导数，梯度的方向为该点具有最大方向导数的方向。
哈密顿引入算子▽(读作 Del)表示下面矢量
$\nabla = e_{x}\frac{\partial}{\partial x} + e_{y}\frac{\partial}{\partial y} + e_{z}\frac{\partial}{\partial z}$
(1-4-6)
那么，根据式(1-4-5)，标量场φ的梯度
gradφ可以表示为算子▽与标量φ的乘积，即
gradφ=▽φ (1-4-7)
标量φ(x，y，z)等于常数的空间曲面称为标量场的等值面。所以，某点梯度的三个坐标分量是标量场等值面通过该点法线的三个方向数，这就意味着梯度的方向为等值面的法线方向。因此，梯度的方向与等值面垂直，且指向标量场数值增大的方向。
读者可以证明，梯度的运算符合下列规则：
▽C=0 (C为常数) (1-4-8)
▽(Cφ)=C▽φ (C为常数) (1-4-9)
▽(φ+Ψ)=▽φ+▽Ψ (1-4-10)

**例1-4-1** 已知标量场
$\varphi\left( x,y,z \right) = x^{2}y + y^{2}z + 1,$求(2，1，3)处方向导数的最大值。
解 根据梯度的定义式(1-4-5)，求得该标量场φ的梯度▽φ为
$\nabla\Phi = 2xye_{x} + \left( x^{2} + 2yz \right)e_{y} + y^{2}e_{z}$
那么在(2，1，3)处的梯度为 $\nabla\Phi = 4e_{x} + 10e_{y} + e_{z},$其模为
$\mid \nabla\Phi \mid = \sqrt{117},$因此，在(2，1，3)处方向导数的最大值为
$\sqrt{117}。$
**例1-4-2** 计算 $\nabla\left( \frac{1}{R} \right)$ 及
$\nabla'\left( \frac{1}{R} \right)。$ 这里R为空间 P 点与
P\'点之间的距离，R≠0，如图1-4-2所示。P
点的坐标为(x,y,z),P\'点的坐标为(x\',y\',z\'),▽表示对x,y,z运算,▽\'表示对x\',y\',z\'运算。![](media/image8.jpeg){width="2.375in"
height="1.6388888888888888in"}
解 令 P 点的位置矢量为 r，P\'点的位置矢量为r\'，则
 $r = xe_{x} + ye_{y} + ze_{z}$
$r' = x'e_{x} + y'e_{y} + z'e_{z}$
再令 R=r-r\'
则
$R = \left( x - x' \right)e_{x} + \left( y - y' \right)e_{y} + \left( z - z' \right)e_{z}$
$R = \mid R \mid = \sqrt{\left( x - x' \right)^{2} + \left( y - y' \right)^{2} + \left( z - z' \right)^{2}}$
根据题意，算子▽及▽\'分别为
$\nabla = e_{x}\frac{\partial}{\partial x} + e_{y}\frac{\partial}{\partial y} + e_{z}\frac{\partial}{\partial z}$
$\nabla' = e_{x}\frac{\partial}{\partial x'} + e_{y}\frac{\partial}{\partial y'} + e_{z}\frac{\partial}{\partial z'},$
因此
$\nabla\left( \frac{1}{R} \right) = e_{x}\frac{\partial}{\partial x}\left( \frac{1}{R} \right) + e_{y}\frac{\partial}{\partial y}\left( \frac{1}{R} \right) + e_{z}\frac{\partial}{\partial z}\left( \frac{1}{R} \right)$
$= - \frac{1}{R^{3}}\left\lbrack \left( x - x' \right)e_{x} + \left( y - y' \right)e_{y} + \left( z - z' \right)e_{z} \right\rbrack$
即 $\nabla\left( \frac{1}{R} \right) = - \frac{R}{R^{3}}$ (1-4-14)
同理可得
$\nabla'\left( \frac{1}{R} \right) = \frac{R}{R^{3}}$ (1-4-15)
由此可见
$\nabla\left( \frac{1}{R} \right) = - \nabla'\left( \frac{1}{R} \right)$
(1-4-16)
上述运算过程及其结果在电磁场计算中经常遇到，通常以(x\'，y\'，z\')表示产生电磁场的源坐标，以(x，y，z)表示空间电磁场的场坐标。这样，图1-4-2中，P\'表示源点，P表示场点。当计算某一分布源在空间某点产生的场强时，P\'为动点，P为定点；当计算空间场量的分布特性或者空间某点各个场量之间的关系时，P\'为定点，P为动点。
