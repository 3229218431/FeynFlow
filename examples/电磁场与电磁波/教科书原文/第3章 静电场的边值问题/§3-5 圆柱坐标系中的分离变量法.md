# §3-5 圆柱坐标系中的分离变量法

电位满足的拉普拉斯方程式(3-1-2)在圆柱坐标系中的展开式为

$$\frac{1}{r}\frac{\partial}{\partial r}\left(r\frac{\partial\varphi}{\partial r}\right) + \frac{1}{r^{2}}\frac{\partial^{2}\varphi}{\partial\varphi^{2}} + \frac{\partial^{2}\varphi}{\partial z^{2}} = 0 \quad \text{(3-5-1)}$$

令其解为

$$\varphi(r,\varphi,z) = R(r)\Phi(\varphi)Z(z) \quad \text{(3-5-2)}$$

代入式(3-5-1)中，得

$$\frac{r}{R}\frac{d}{dr}\left(r\frac{dR}{dr}\right) + \frac{1}{\Phi}\frac{d^{2}\Phi}{d\varphi^{2}} + \frac{r^{2}}{Z}\frac{d^{2}Z}{dz^{2}} = 0 \quad \text{(3-5-3)}$$

上式中第二项仅为变量φ的函数，而第一项及第三项与φ无关，因此将上式对φ求导，得知第二项对φ的导数为零，可见第二项应为常数，令

$$\frac{1}{\Phi}\frac{d^{2}\Phi}{d\varphi^{2}} = -k_{\varphi}^{2} \quad \text{(3-5-4)}$$

即

$$\frac{d^{2}\Phi}{d\varphi^{2}} + k_{\varphi}^{2}\Phi = 0 \quad \text{(3-5-5)}$$

式中，kφ为分离常数。由前节知，它可以是实数或虚数。对于很多实际问题，变量φ的变化范围为0≤φ<2π。那么，场量随φ的变化是以2π为周期的周期函数。因此，方程式(3-5-4)的解一定是三角函数，且常数kφ一定是整数，以保证函数Φ(φ)的周期为2π。令kφ=m，m为整数，则方程式(3-5-4)的解为

$$\Phi(\varphi) = A\sin m\varphi + B\cos m\varphi \quad \text{(3-5-6)}$$

式中，A，B为待定常数。

考虑到式(3-5-4)，则式(3-5-3)可以写为

$$\left[ \frac{1}{Rr}\frac{d}{dr}\left(r\frac{dR}{dr}\right) - \frac{m^{2}}{r^{2}} \right] + \frac{1}{Z}\frac{d^{2}Z}{dz^{2}} = 0 \quad \text{(3-5-7)}$$

上式左边第一项仅为变量r的函数，第二项仅为变量z的函数，因此与前同理，它们应分别等于常数，令

$$\frac{1}{Z}\frac{d^{2}Z}{dz^{2}} = k_{z}^{2} \quad \text{(3-5-8)}$$

即

$$\frac{d^{2}Z}{dz^{2}} - k_{z}^{2}Z = 0 \quad \text{(3-5-9)}$$

式中，分离常数k₂可为实数或虚数，其解的形式可取三角函数、双曲函数或幂函数。当k₂为虚数时，可令

$$Z(z) = C\sin|k_{z}|z + D\cos|k_{z}|z \quad \text{(3-5-10)}$$

式中，C，D为待定常数。

将式(3-5-8)代入式(3-5-7)中，得

$$r^{2}\frac{d^{2}R}{dr^{2}} + r\frac{dR}{dr} + (k_{z}^{2}r^{2} - m^{2})R = 0 \quad \text{(3-5-11)}$$

若令$k_{z}^{2}r^{2} = x^{2}$，则上式变为

$$x^{2}\frac{d^{2}R}{dx^{2}} + x\frac{dR}{dx} + (x^{2} - m^{2})R = 0 \quad \text{(3-5-12)}$$

该式为标准的贝塞尔方程，其解为贝塞尔函数，即

$$R(r) = EJ_{m}(k_{z}r) + FN_{m}(k_{z}r) \quad \text{(3-5-13)}$$

式中，E，F为待定常数，Jm(k₂r)为m阶第一类贝塞尔函数，Nm(k₂r)为m阶第二类贝塞尔函数。由附录六获知，当r=0时，各阶第二类贝塞尔函数$N_{m}(k_{z}r) \rightarrow -\infty$。因此，若场区包括r=0时，不能选择第二类贝塞尔函数Nm(k₂r)作为解的组成函数。

至此，我们得知方程式(3-5-1)的解应为式(3-5-6)、式(3-5-10)及式(3-5-13)的乘积，或取其线性组合。

若所讨论的静电场与z无关，则由式(3-5-8)知k₂=0。那么，式(3-5-11)变为

$$r^{2}\frac{d^{2}R}{dr^{2}} + r\frac{dR}{dr} - m^{2}R = 0 \quad \text{(3-5-14)}$$

该方程的解为指数函数，即

$$R(r) = Er^{m} + Fr^{-m}, \quad m \neq 0 \quad \text{(3-5-15)}$$

若所讨论的静电场与φ无关，则m=0。若场量又与z无关，则式(3-5-11)的解为

$$R(r) = A_{0}\ln r + B_{0} \quad \text{(3-5-16)}$$

因此，若静电场与z无关，方程式(3-5-1)的解可取下列一般形式

$$\varphi(r,\varphi) = A_{0}\ln r + \sum_{m=1}^{\infty} r^{m}(A_{m}\sin m\varphi + B_{m}\cos m\varphi) + \sum_{m=1}^{\infty} r^{-m}(C_{m}\sin m\varphi + D_{m}\cos m\varphi) \quad \text{(3-5-17)}$$

**例3-5-1** 设一根无限长、半径为a的导体圆柱放入无限大的均匀静电场E₀中，E₀方向垂直于导体圆柱，如图3-5-1所示。试求导体圆柱外的电场强度。

解 选取圆柱坐标系，令z轴为圆柱轴线，电场强度E₀的方向与x轴一致，即$E_{0} = e_{x}E_{0}$。

当导体圆柱处于静电平衡时，柱内电场强度为零，圆柱为等位体，圆柱表面电场强度切向分量为零。由于圆柱为无限长，因而柱外的电位分布函数与z无关。解的形式可取式(3-5-17)，它应满足下列两个边界条件：

(1) 圆柱表面电场强度的切向分量为零。由

$$E = -\nabla\varphi = -\left[ e_{r}\frac{\partial\varphi}{\partial r} + e_{\varphi}\frac{1}{r}\frac{\partial\varphi}{\partial\varphi} + e_{z}\frac{\partial\varphi}{\partial z} \right]$$

求得

$$E_{\varphi} = -e_{\varphi}\frac{1}{r}\frac{\partial\varphi}{\partial\varphi}\bigg|_{r=a} = 0$$

因此，

$$\frac{\partial\varphi}{\partial\varphi}\bigg|_{r=a} = 0 \quad \text{(3-5-18)}$$

(2) 在r→∞区域内，圆柱的影响可以忽略，场未受到任何扰动，其电位应为

$$\varphi(\infty,\varphi) = -E_{0}x = -E_{0}r\cos\varphi \quad \text{(3-5-19)}$$

上式成立是显而易见的。根据E=-∇φ，取式(3-5-19)定义的电位函数的梯度负值，即求得原来的均匀场E₀。

式(3-5-19)表明，当r→∞时，电位函数仅为r和cosφ的函数，可见式(3-5-17)中系数$A_{0} = A_{m} = C_{m} = 0$，且m=1。因此电位函数为

$$\varphi(r,\varphi) = B_{1}r\cos\varphi + \frac{D_{1}}{r}\cos\varphi \quad \text{(3-5-20)}$$

将此结果代入式(3-5-18)，得

$$-B_{1}a\sin\varphi - \frac{D_{1}}{a}\sin\varphi = 0$$

即

$$D_{1} = -B_{1}a^{2} \quad \text{(3-5-21)}$$

又知当r→∞时，φ = -E₀r cosφ，得

$$B_{1}r\cos\varphi = -E_{0}r\cos\varphi$$

即

$$B_{1} = -E_{0} \quad \text{(3-5-22)}$$

将此结果代入式(3-5-21)中，得

$$D_{1} = E_{0}a^{2} \quad \text{(3-5-23)}$$

将式(3-5-22)及式(3-5-23)代入式(3-5-20)中，求得柱外电位分布函数为

$$\varphi(r,\varphi) = -E_{0}r\cos\varphi + \frac{E_{0}a^{2}}{r}\cos\varphi \quad \text{(3-5-24)}$$

则柱外电场强度为

$$E = -\nabla\varphi = -e_{r}\frac{\partial\varphi}{\partial r} - e_{\varphi}\frac{1}{r}\frac{\partial\varphi}{\partial\varphi} - e_{z}\frac{\partial\varphi}{\partial z}$$

$$= e_{r}\left(1 + \frac{a^{2}}{r^{2}}\right)E_{0}\cos\varphi - e_{\varphi}\left(1 - \frac{a^{2}}{r^{2}}\right)E_{0}\sin\varphi \quad \text{(3-5-25)}$$

读者可以验证，当r→∞时，上式结果与式(3-5-19)求出的电场强度一定相等。

根据所得的结果，图3-5-1中给出了圆柱外电场线及等位面的分布，实线表示电场线，虚线表示等位面。
