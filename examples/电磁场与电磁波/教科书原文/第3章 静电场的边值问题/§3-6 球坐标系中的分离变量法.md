# §3-6 球坐标系中的分离变量法

电位满足的拉普拉斯方程式(3-1-2)在球坐标系中展开式为

$$\frac{1}{r^{2}}\frac{\partial}{\partial r}\left(r^{2}\frac{\partial\varphi}{\partial r}\right) + \frac{1}{r^{2}\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial\varphi}{\partial\theta}\right) + \frac{1}{r^{2}\sin^{2}\theta}\frac{\partial^{2}\varphi}{\partial\varphi^{2}} = 0 \quad \text{(3-6-1)}$$

令其解为

$$\varphi(r,\theta,\varphi) = R(r)\Theta(\theta)\Phi(\varphi) \quad \text{(3-6-2)}$$

代入式(3-6-1)中，得

$$\frac{\sin^{2}\theta}{R}\frac{d}{dr}\left(r^{2}\frac{dR}{dr}\right) + \frac{\sin\theta}{\Theta}\frac{d}{d\theta}\left(\sin\theta\frac{d\Theta}{d\theta}\right) + \frac{1}{\Phi}\frac{d^{2}\Phi}{d\varphi^{2}} = 0 \quad \text{(3-6-3)}$$

与前同理，上式第三项应为常数，令

$$\frac{1}{\Phi}\frac{d^{2}\Phi}{d\varphi^{2}} = -m^{2} \quad \text{(3-6-4)}$$

即

$$\frac{d^{2}\Phi}{d\varphi^{2}} + m^{2}\Phi = 0 \quad \text{(3-6-5)}$$

由上节得知，当0≤φ<2π时，上式的解一定是三角函数，且m一定是整数，因此

$$\Phi(\varphi) = A\sin m\varphi + B\cos m\varphi \quad \text{(3-6-6)}$$

将式(3-6-4)代入式(3-6-2)中，得

$$\frac{1}{R}\frac{d}{dr}\left(r^{2}\frac{dR}{dr}\right) + \left[\frac{1}{\Theta\sin\theta}\frac{d}{d\theta}\left(\sin\theta\frac{d\Theta}{d\theta}\right) - \frac{m^{2}}{\sin^{2}\theta}\right] = 0 \quad \text{(3-6-7)}$$

可见，上式中第一项仅为r的函数，第二项与r无关，因此，与前同理，第一项应为常数。为了便于进一步求解，令

$$\frac{1}{R}\frac{d}{dr}\left(r^{2}\frac{dR}{dr}\right) = n(n+1) \quad \text{(3-6-8)}$$

式中，n为整数。上式又可写为

$$r^{2}\frac{d^{2}R}{dr^{2}} + 2r\frac{dR}{dr} - n(n+1)R = 0 \quad \text{(3-6-9)}$$

这是欧拉方程，其通解为

$$R(r) = Cr^{n} + \frac{D}{r^{n+1}} \quad \text{(3-6-10)}$$

将式(3-6-8)代入式(3-6-7)中，得

$$\frac{d}{d\theta}\left(\sin\theta\frac{d\Theta}{d\theta}\right) + \Theta\left[n(n+1)\sin\theta - \frac{m^{2}}{\sin\theta}\right] = 0 \quad \text{(3-6-11)}$$

令cosθ=x，则

$$\frac{d\Theta}{d\theta} = \frac{d\Theta}{dx}\frac{dx}{d\theta} = -\sin\theta\frac{d\Theta}{dx} = -\sqrt{1-x^{2}}\frac{d\Theta}{dx}$$

那么式(3-6-11)又可写为

$$\frac{d}{dx}\left[(1-x^{2})\frac{d\Theta}{dx}\right] + \Theta\left[n(n+1) - \frac{m^{2}}{1-x^{2}}\right] = 0 \quad \text{(3-6-12)}$$

由附录七知，上式为连带勒让德方程，其通解为第一类连带勒让德函数$P_{n}^{m}(x)$与第二类连带勒让德函数$Q_{n}^{m}(x)$之和，这里m<n。根据勒让德函数特性得知，当n是整数时，$P_{n}^{m}(x)$及$Q_{n}^{m}(x)$为有限项多项式。因此，我们在建立方程式(3-6-8)时，要求n为整数。根据第二类连带勒让德函数$Q_{n}^{m}(x)$的特性获知，当x=±1时，$Q_{n}^{m}(x) \rightarrow \pm\infty$。因此，当场区包括θ=0或π时，因为x=±1，只能取第一类连带勒让德函数$P_{n}^{m}(x)$作为式(3-6-12)的解。所以，通常取

$$\Theta(\theta) = P_{n}^{m}(x) = P_{n}^{m}(\cos\theta) \quad \text{(3-6-13)}$$

将式(3-6-6)、式(3-6-10)及式(3-6-13)代入式(3-6-2)中，再取其线性组合，式(3-6-1)的通解为

$$\varphi(r,\theta,\varphi) = \sum_{m=0}^{n}\sum_{n=0}^{\infty} (A_{m}\sin m\varphi + B_{m}\cos m\varphi) \cdot (C_{n}r^{n} + D_{n}r^{-(n+1)})P_{n}^{m}(\cos\theta) \quad \text{(3-6-14)}$$

若静电场与φ无关，则m=0。那么$P_{n}^{0}(x) = P_{n}(x)$称为第一类勒让德函数，此时，方程式(3-6-1)的通解为

$$\varphi(r,\theta) = \sum_{n=0}^{\infty} (C_{n}r^{n} + D_{n}r^{-(n+1)})P_{n}(\cos\theta) \quad \text{(3-6-15)}$$

**例3-6-1** 设半径为a，介电常数为ε的介质球放在无限大的真空中，其内存在的均匀静电场为E₀，如图3-6-1所示。试求介质球内的电场强度。

解 取球坐标系，令$E_{0} = E_{0}e_{z}$。显然，此时场分布以z轴为旋转对称，因此与φ无关。同时考虑到θ=0，π位于场区。这样，球内、外的电位分布函数应取式(3-6-15)形式。

令φᵢ为球内电位，φ₀为球外电位，则

$$\varphi_{i}(r,\theta) = \sum_{n=0}^{\infty} C_{n}r^{n}P_{n}(\cos\theta) + \sum_{n=0}^{\infty} D_{n}r^{-(n+1)}P_{n}(\cos\theta) \quad \text{(3-6-16)}$$
$$\varphi_{o}(r,\theta) = \sum_{n=0}^{\infty} A_{n}r^{n}P_{n}(\cos\theta) + \sum_{n=0}^{\infty} B_{n}r^{-(n+1)}P_{n}(\cos\theta) \quad \text{(3-6-17)}$$

式中，系数Cn, Dn及An, Bn取决于边界条件。

球内、外电位函数应该满足下列边界条件：

(1) 球心电位φᵢ(0,θ)应为有限值。

(2) 无限远处电位应为

$$\varphi_{o}(\infty,\theta) = -E_{0}r\cos\theta = -E_{0}rP_{1}(\cos\theta)$$

(3) 球内电位φᵢ与球外电位φ₀在r=a的球面上应该连续，即

$$\varphi_{i}(a,\theta) = \varphi_{o}(a,\theta)$$

(4) 根据边界上电通密度法向分量的连续性，获知球面上内、外电位的法向导数应该满足

$$-\varepsilon\left(\frac{\partial\varphi_{i}}{\partial r}\right)_{r=a} = -\varepsilon_{0}\left(\frac{\partial\varphi_{o}}{\partial r}\right)_{r=a}$$

考虑到边界条件(1)，式(3-6-16)中系数Dn应为零，即

$$\varphi_{i}(r,\theta) = \sum_{n=0}^{\infty} C_{n}r^{n}P_{n}(\cos\theta) \quad \text{(3-6-18)}$$

为了满足边界条件(2)，式(3-6-17)中除了A₁以外的系数An应皆为零，且$A_{1} = -E_{0}$，即

$$\varphi_{o}(r,\theta) = -E_{0}rP_{1}(\cos\theta) + \sum_{n=0}^{\infty} B_{n}r^{-(n+1)}P_{n}(\cos\theta) \quad \text{(3-6-19)}$$

再考虑到边界条件(3)，由式(3-6-18)及式(3-6-19)得

$$\sum_{n=0}^{\infty} C_{n}a^{n}P_{n}(\cos\theta) = -E_{0}aP_{1}(\cos\theta) + \sum_{n=0}^{\infty} B_{n}a^{-(n+1)}P_{n}(\cos\theta) \quad \text{(3-6-20)}$$

为了进一步满足边界条件(4)，由式(3-6-18)及式(3-6-19)，得

$$-\sum_{n=0}^{\infty} \varepsilon_{r}nC_{n}a^{n-1}P_{n}(\cos\theta) = E_{0}P_{1}(\cos\theta) + \sum_{n=0}^{\infty} (n+1)B_{n}a^{-(n+2)}P_{n}(\cos\theta) \quad \text{(3-6-21)}$$

式中，$\varepsilon_{r} = \varepsilon/\varepsilon_{0}$。

由于式(3-6-20)及式(3-6-21)对于所有的θ值均应满足，因此等式两边对应的各项系数应该相等。求解上述方程组，得

$$B_{0} = C_{0} = 0$$
$$B_{1} = E_{0}a^{3}\left(\frac{\varepsilon_{r} - 1}{\varepsilon_{r} + 2}\right)$$
$$C_{1} = -\frac{3E_{0}}{\varepsilon_{r} + 2}$$
$$B_{n} = C_{n} = 0, \quad (n \geq 2)$$

将此结果代入式(3-6-18)及式(3-6-19)中，得

$$\varphi_{i}(r,\theta) = -\frac{3E_{0}}{\varepsilon_{r} + 2}r\cos\theta = -\frac{3E_{0}}{\varepsilon_{r} + 2}z \quad \text{(3-6-25)}$$
$$\varphi_{o}(r,\theta) = -E_{0}r\cos\theta + \frac{\varepsilon_{r} - 1}{\varepsilon_{r} + 2}\frac{E_{0}a^{3}}{r^{2}}\cos\theta \quad \text{(3-6-26)}$$

由式(3-6-25)求得球内的电场强度为

$$E_{i} = -\frac{\partial\varphi_{i}}{\partial z}e_{z} = \frac{3E_{0}\varepsilon_{0}}{\varepsilon + 2\varepsilon_{0}}e_{z} \quad \text{(3-6-27)}$$

此式表明，球内电场仍然保持为均匀电场。因ε>ε₀，球内场强低于球外场强，这是由于介质球被极化后出现的束缚电荷产生的电场抵消了一部分外加电场所导致的。

读者可以设想，如果在无限大的介电常数为ε的均匀介质中存在球形气泡，那么仅将式(3-6-27)中ε₀与ε对调，即可推知当外加均匀电场为$E_{0} = e_{z}E_{0}$时，气泡中的电场强度Eᵢ应为

$$E_{i} = \frac{3\varepsilon E_{0}}{\varepsilon_{0} + 2\varepsilon}e_{z} \quad \text{(3-6-28)}$$

此式表明，气泡中的场强高于气泡外的场强。因此，电气设备中浇注变压器油或环氧树脂时，应尽量避免作为绝缘材料使用的变压器油或环氧树脂中出现气泡。否则，由于气泡中电场较强有可能发生电压击穿，导致绝缘性能显著恶化。
