# §3-4 直角坐标系中的分离变量法

电位满足的拉普拉斯方程式(3-1-2)在直角坐标系中的展开式为

$$\frac{\partial^{2}\varphi}{\partial x^{2}} + \frac{\partial^{2}\varphi}{\partial y^{2}} + \frac{\partial^{2}\varphi}{\partial z^{2}} = 0 \quad \text{(3-4-1)}$$

令其解为三个坐标变量函数的乘积，即

$$\varphi(x,y,z) = X(x)Y(y)Z(z) \quad \text{(3-4-2)}$$

式中，函数X(x), Y(y), Z(z)分别仅为变量x, y, z的函数。

将式(3-4-2)代入式(3-4-1)中，两边再除以X(x)Y(y)Z(z)，得

$$\frac{1}{X}\frac{d^{2}X}{dx^{2}} + \frac{1}{Y}\frac{d^{2}Y}{dy^{2}} + \frac{1}{Z}\frac{d^{2}Z}{dz^{2}} = 0 \quad \text{(3-4-3)}$$

显然，式中的每项仅与一个变量有关。因此，将上式对变量x求导，第二及第三项为零，求得第一项对x的导数为零，说明了第一项等于常数。同理，将式(3-4-3)分别对变量y及z求导，得知第二项及第三项也分别等于常数。令各项的常数分别为$-k_{x}^{2}, -k_{y}^{2}, -k_{z}^{2}$，即

$$\frac{d^{2}X}{dx^{2}} + k_{x}^{2}X = 0 \quad \text{(3-4-4a)}$$
$$\frac{d^{2}Y}{dy^{2}} + k_{y}^{2}Y = 0 \quad \text{(3-4-4b)}$$
$$\frac{d^{2}Z}{dz^{2}} + k_{z}^{2}Z = 0 \quad \text{(3-4-4c)}$$

式中，kₓ, kᵧ, k₂称为分离常数，它们可以是实数或虚数。显然，由于式(3-4-3)成立，三个分离常数kₓ, kᵧ, k₂并不是独立的，由式(3-4-3)可知，它们必须满足下列方程

$$k_{x}^{2} + k_{y}^{2} + k_{z}^{2} = 0 \quad \text{(3-4-5)}$$

由上式可见，经过变量分离后，三维偏微分方程式(3-4-1)被简化为三个一维常微分方程，如式(3-4-4)所示。常微分方程的求解较为简便，而且式(3-4-4)所表示的三个常微分方程又具有同一结构，因此它们解的结构也一定相同。

式(3-4-4a)的通解为

$$X(x) = Ae^{-jk_{x}x} + Be^{jk_{x}x} \quad \text{(3-4-6)}$$

式中，A，B为待定常数。上式也可写成三角函数形式

$$X(x) = C\sin k_{x}x + D\cos k_{x}x \quad \text{(3-4-7)}$$

式中，C，D为待定常数。

式(3-4-4)中的分离常数也可为虚数。当kₓ为虚数时，令$k_{x} = j\alpha$，则式(3-4-6)变为

$$X(x) = Ae^{\alpha x} + Be^{-\alpha x} \quad \text{(3-4-8)}$$

而式(3-4-7)变为双曲函数

$$X(x) = C\sinh\alpha x + D\cosh\alpha x \quad \text{(3-4-9)}$$

式(3-4-4b)及式(3-4-4c)的解具有完全相同的形式。通常，为了满足给定的边界条件，必须选取解的线性组合作为方程的解。解的函数选择完全决定于给定的边界条件，解中各个常数也取决于给定的边界条件。将三个方程求得的解代入式(3-4-2)中，即得式(3-4-1)的解。

**例3-4-1** 两个相互平行的半无限大接地导体平面，间距为d，其有限端被电位为φ₀的导电平面封闭，且与半无限大接地导体平面绝缘，如图3-4-1所示。试求三个导体平面形成的槽中的电位分布。

解 选取直角坐标系，如图3-4-1所示。由于导电平面沿z轴无限延伸，槽中电位分布函数一定与z无关，因此，这是一个二维场的问题。电位所满足的拉普拉斯方程式(3-4-1)变为

$$\frac{\partial^{2}\varphi}{\partial x^{2}} + \frac{\partial^{2}\varphi}{\partial y^{2}} = 0 \quad \text{(3-4-10)}$$

根据题意，槽中电位应满足的边界条件可表示为

φ(0,y) = φ₀

φ(∞,y) = 0

φ(x,0) = 0

φ(x,d) = 0

根据分离变量法，可令式(3-4-10)的解为

φ(x,y) = X(x)Y(y)

为了满足φ(x,0)=0及φ(x,d)=0的边界条件，应选Y(y)的解为

Y(y) = A sin kᵧ y + B cos kᵧ y

由边界条件φ(x,0)=0知，y=0时，φ=0，因此上式中常数B=0。为了满足φ(x,d)=0，分离常数kᵧ应为

$$k_{y} = \frac{n\pi}{d}, \quad n = 1, 2, 3, \cdots$$

那么

$$Y(y) = A\sin\left(\frac{n\pi}{d}y\right)$$

已知$k_{x}^{2} + k_{y}^{2} = 0$，将kᵧ=nπ/d代入，得

$$k_{x} = j\frac{n\pi}{d}$$

可见，分离常数kₓ为虚数，故X(x)的解应为

$$X(x) = Ce^{\frac{n\pi}{d}x} + De^{-\frac{n\pi}{d}x}$$

由边界条件φ(∞,y)=0得知，x=∞时，φ=0。因此，上式中常数C=0，即

$$X(x) = De^{-\frac{n\pi}{d}x}$$

将Y(y)及X(x)代入φ(x,y)=X(x)Y(y)中，得

$$\varphi(x,y) = Ce^{-\frac{n\pi}{d}x}\sin\left(\frac{n\pi}{d}y\right)$$

式中，常数C=AD。由边界条件φ(0,y)=φ₀知，当x=0时，φ=φ₀，代入得

$$\varphi_{0} = C\sin\left(\frac{n\pi}{d}y\right)$$

上式右端为变量，左端为常量，因此不能成立，这就表明上式不能满足边界条件φ(0,y)=φ₀。为此，取解的线性组合作为方程式(3-4-10)的解，即

$$\varphi(x,y) = \sum_{n=1}^{\infty} C_{n}e^{-\frac{n\pi}{d}x}\sin\left(\frac{n\pi}{d}y\right) \quad \text{(3-4-17)}$$

为了满足φ(0,y)=φ₀的边界条件，由上式得

$$\varphi_{0} = \sum_{n=1}^{\infty} C_{n}\sin\left(\frac{n\pi}{d}y\right), \quad 0 \leq y \leq d$$

上式右端为傅里叶级数。利用傅里叶级数的正交性，可以求出系数Cn。为此，以$\sin(m\pi y/d)$乘以等式两边，并在区间0≤y≤d内对y求积，得

$$\int_{0}^{d} \varphi_{0}\sin\left(\frac{m\pi}{d}y\right)dy = \sum_{n=1}^{\infty} \int_{0}^{d} C_{n}\sin\left(\frac{n\pi}{d}y\right)\sin\left(\frac{m\pi}{d}y\right)dy$$

利用傅里叶级数的正交性，只有m=n单项存在，其余各项皆为零。求得系数Cn为

$$C_{n} = \begin{cases} \frac{4\varphi_{0}}{n\pi}, & n\text{为奇数} \ 0, & n\text{为偶数} \end{cases}$$

将此结果代入式(3-4-17)，求得槽中电位分布函数为

$$\varphi(x,y) = \frac{4\varphi_{0}}{\pi}\sum_{n=1,3,5,\cdots}^{\infty} \frac{1}{n}e^{-\frac{n\pi}{d}x}\sin\left(\frac{n\pi}{d}y\right) \quad \text{(3-4-22)}$$

式中，n=1，3，5，...。由上式可见，当n增大或者x>d时，级数收敛很快。当x≫d时，仅取前几项即可。当x≪d时，级数收敛很慢，应多取几项。根据式(3-4-22)结果，在图3-4-1中绘制了槽中电场线及等位面的分布，图中虚线表示电位分布，实线表示电场线分布。
