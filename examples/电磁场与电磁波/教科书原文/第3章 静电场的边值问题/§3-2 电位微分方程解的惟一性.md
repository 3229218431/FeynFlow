# §3-2 电位微分方程解的惟一性

我们已知，静电场的边值问题归结为给定的边界条件下求解电位微分方程。现在证明，电位满足的泊松方程在给定第一类边界条件或第二类边界条件时，也就是当边界上的电位或者电位的法向导数值给定时，其解是惟一的。

这里采用反证法予以证明。设静电场存在的区域为V，其边界表面为S。如果在给定第一类或第二类边界条件时，V中存在两个电位φ₁及φ₂均满足泊松方程，即

$$\nabla^{2}\varphi_{1} = -\frac{\rho}{\varepsilon}; \quad \nabla^{2}\varphi_{2} = -\frac{\rho}{\varepsilon}$$

令φ₁-φ₂=δφ，显然电位差δφ满足拉普拉斯方程，即

$$\nabla^{2}(\delta\varphi) = 0 \quad \text{(3-2-1)}$$

利用第一标量格林定理，并令φ=ψ=δφ，则由式(1-8-1)得

$$\int_{V} \left[ |\nabla\delta\varphi|^{2} + \delta\varphi\nabla^{2}(\delta\varphi) \right] dV = \oint_{S} \delta\varphi\frac{\partial}{\partial n}(\delta\varphi) dS$$

将式(3-2-1)代入，得

$$\int_{V} |\nabla\delta\varphi|^{2} dV = \oint_{S} \delta\varphi\frac{\partial}{\partial n}(\delta\varphi) dS \quad \text{(3-2-2)}$$

由此可见，当边界S上的电位或其法向导数给定时，在边界S上的电位差δφ或其法向导数∂(δφ)/∂n应该为零，即式(3-2-2)的右端面积分为零，即

$$\int_{V} |\nabla(\delta\varphi)|^{2} dV = 0 \quad \text{(3-2-3)}$$

由于上式中的被积函数为正，因此只有当被积函数为零时积分值才为零，由此得

$$\nabla(\delta\varphi) = 0 \quad \text{(3-2-4)}$$

此式表明，电位差δφ是一个常数，即

$$\varphi_{1} - \varphi_{2} = \text{常数}$$

由此可见，若边界上电位值给定，则在边界上，φ₁=φ₂。因此，既然φ₁与φ₂的差值是一个常数，这个常数应该处处为零，即在V中，φ₁=φ₂。这就说明了当边界上的电位给定时，泊松方程的解是惟一的。

如果给定的是边界上的电位法向导数值，那么φ₁与φ₂的差值不一定为零，但由于φ₁与φ₂只相差一个常数，电场强度E=-∇φ，因此这个常数并不影响电场强度。也就是说，根据φ₁或φ₂求得的电场强度是相同的，从这个意义来看，我们仍然可以认为电位微分方程的解是惟一的。

实际中，静电场的边界通常是由导体形成的。此时，若给定导体上的电位值就是第一类边界，则给定导体上的电荷分布就是第二类边界。因为由式(2-6-12)得知，导体表面上的电荷密度与电位导数的关系为

$$\frac{\partial\varphi}{\partial n} = -\frac{\rho_{s}}{\varepsilon}$$

可见，表面电荷给定等于给定了电位的法向导数值。因此，当导体上的电荷分布给定时，空间静电场的解也是惟一的。

由以上讨论得知，对于导体边界的静电场问题，当边界上的电位或电位的法向导数给定时，或导体表面电荷分布给定时，空间的静电场被惟一地确定。这个结论称为静电场惟一性定理。读者可以证明，该定理同样适用非均匀介质。注意，对于非均匀介质，电位满足的微分方程应为∇·(ε∇φ)=-ρ。

应该指出，电位微分方程解的惟一性以及静电场的惟一性定理是镜像法和分离变量法的依据。
