# §4-5 导电介质的损耗

在导电介质中，自由电子移动时要与原子晶格发生碰撞，结果产生热能，这是一种不可逆的能量转换。这种能量损耗将由外源不断补给，以维持恒定的电流。

设在恒定电流场中，沿电流方向取一个长度为dl，端面为dS的小圆柱体，如图4-5-1所示。该圆柱体的两个端面分别为两个等位面。若在电场力作用下，dt时间内有dq电荷自圆柱的左端移至右端，那么电场力作的功为

$$dW = dqE \cdot dl = E dq dl$$

电场损失的功率P为

$$P = \frac{dW}{dt} = E\frac{dq}{dt}dl = EIdl = EJ dS dl$$

式中，$dS dl = dV$为小圆柱的体积。因此，单位体积中的功率损耗，也就是功率损耗密度为

$$p_{l} = EJ = \sigma E^{2} = \frac{J^{2}}{\sigma} \quad \text{(4-5-1)}$$

当J和E的方向不同时，上式可以表示为下面矢量形式

$$p_{l} = E \cdot J \quad \text{(4-5-2)}$$

它表示导电介质中某点功率损耗密度等于该点的电场强度与电流密度的标积。

设圆柱体两端的电位差为U，则$E = U/dl$，又知$J = I/dS$，那么功率损耗密度可表示为

$$p_{l} = \frac{UI}{dS dl} = \frac{UI}{dV}$$

可见，圆柱体中的总功率损耗为

$$P = p_{l}dV = UI \quad \text{(4-5-3)}$$

这就是电路中的焦耳定律，式(4-5-2)称为焦耳定律的微分形式。

**例4-5-1** 已知一平板电容器由两层非理想介质串联构成。其介电常数分别为ε₁和ε₂，电导率分别为σ₁和σ₂，厚度分别为d₁和d₂。当外加恒定电压为U时，试求两层介质中的电场强度、电场储能密度及功率损耗密度。

解 由于电容器外部不存在电流，可以认为电容器中的电流线与边界垂直，则由式(4-4-2)得

$$E_{1}\sigma_{1} = E_{2}\sigma_{2}$$

又

$$E_{1}d_{1} + E_{2}d_{2} = U$$

由此求得

$$E_{1} = \frac{\sigma_{2}}{d_{1}\sigma_{2} + d_{2}\sigma_{1}}U; \quad E_{2} = \frac{\sigma_{1}}{d_{1}\sigma_{2} + d_{2}\sigma_{1}}U$$

两种介质中电场储能密度为

$$w_{e1} = \frac{1}{2}\varepsilon_{1}E_{1}^{2}; \quad w_{e2} = \frac{1}{2}\varepsilon_{2}E_{2}^{2}$$

功率损耗密度为

$$p_{l1} = \sigma_{1}E_{1}^{2}; \quad p_{l2} = \sigma_{2}E_{2}^{2}$$

值得注意的是，当σ₁=0时，$E_{1}=U/d_{1}, E_{2}=0, w_{e2}=0, p_{l2}=0$；当σ₂=0时，$E_{1}=0, w_{e1}=0, p_{l1}=0, E_{2}=U/d_{2}$。请读者自行思考为什么会出现这些结果。

**例4-5-2** 设一段均匀环形导电介质，其形状及尺寸如图4-5-3所示。计算两个端面之间的电阻。

解 显然，必须选用圆柱坐标系。设两个端面为理想导体，两个端面之间的电位差为U，φ=0的端面电位为φ₁，φ=π/2的端面电位为φ₂，令φ₁=0，φ₂=U。根据边界条件，两个端面处导体内的电流垂直于端面，又导电介质为均匀介质∇·J=0，可以认为电流沿eφ方向流动，由J=σE，有E沿eφ方向，因此有该导电介质中的电位φ仅与角度φ有关，因此电位φ满足的方程式为

$$\frac{d^{2}\varphi}{d\varphi^{2}} = 0$$

此式通解为

$$\varphi = C_{1}\varphi + C_{2}$$

利用给定的边界条件，求得上式中常数$C_{1} = \frac{2U}{\pi}, C_{2} = 0$，得

$$\varphi = \frac{2U}{\pi}\varphi$$

导电介质中的电流密度J为

$$J = \sigma E = -\sigma\nabla\varphi = -e_{\varphi}\sigma\frac{\partial\varphi}{r\partial\varphi} = -e_{\varphi}\frac{2\sigma U}{\pi r}$$

那么由φ=π/2的端面流进该导电介质的电流I为

$$I = \int_{S} J \cdot dS = \int_{S} \left(-e_{\varphi}\frac{2\sigma U}{\pi r}\right) \cdot (-e_{\varphi} d dr) = \frac{2\sigma Ud}{\pi}\int_{a}^{b} \frac{dr}{r} = \frac{2\sigma Ud}{\pi}\ln\left(\frac{b}{a}\right)$$

因此该导电块的两个端面之间的电阻R为

$$R = \frac{U}{I} = \frac{\pi}{2\sigma d\ln\left(\frac{b}{a}\right)}$$
