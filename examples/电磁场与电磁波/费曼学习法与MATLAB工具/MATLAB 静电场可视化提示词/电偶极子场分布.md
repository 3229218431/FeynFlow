# MATLAB 提示词：电偶极子场分布

## 教科书原文

> 📖 参见：[[§2-5 介质中的静电场]]

## 物理模型

两电荷 ±q 分别位于 (±d/2, 0)，空间电场为两电荷电场的叠加：
$$E_x = kq\left[\frac{x-d/2}{R_1^3} - \frac{x+d/2}{R_2^3}\right]$$
$$E_y = kq\left[\frac{y}{R_1^3} - \frac{y}{R_2^3}\right]$$
其中 $$R_{1,2} = \sqrt{(x\mp d/2)^2 + y^2}$$

## MATLAB 实现提示词

```matlab
% 电偶极子电场分布可视化
q = 1e-9; d = 0.2;      % 电荷和间距
k = 1/(4*pi*8.854e-12);

x = linspace(-2, 2, 60);
y = linspace(-2, 2, 60);
[X, Y] = meshgrid(x, y);

% 正电荷 (+q 在 x=+d/2) 和负电荷 (-q 在 x=-d/2)
R1 = sqrt((X - d/2).^2 + Y.^2);
R2 = sqrt((X + d/2).^2 + Y.^2);
R1(R1<0.02) = NaN; R2(R2<0.02) = NaN;

Ex = k*q*((X-d/2)./R1.^3 - (X+d/2)./R2.^3);
Ey = k*q*(Y./R1.^3 - Y./R2.^3);

% 使用streamline绘制电场线（更美观）
figure;
startx = linspace(-d/2, d/2, 10)';
starty = zeros(10,1);
streamline(X, Y, Ex, Ey, startx, starty);
hold on;
streamline(X, Y, -Ex, -Ey, startx, starty);
axis equal; title('电偶极子电场线');
```

## 远区近似验证

在 MATLAB 中可将精确场与偶极子近似场叠加对比：
```matlab
p = q*d; r = sqrt(X.^2+Y.^2); theta = atan2(Y,X);
Er_approx = p*cos(theta)./(2*pi*8.854e-12*r.^3);
Eth_approx = p*sin(theta)./(4*pi*8.854e-12*r.^3);
% r>5*d 时近似与精确基本一致
```

## 费曼深度讲解

电偶极子是电磁学中最重要的基本结构之一——两个等量异号电荷$+q$和$-q$相距很小距离$d$，构成偶极矩$p=qd$（方向从负电荷指向正电荷）。在远场（$r\gg d$），电偶极子的电位近似为$\varphi(r,\theta)=\frac{p\cos\theta}{4\pi\epsilon_0 r^2}$，电场分量为$E_r=\frac{p\cos\theta}{2\pi\epsilon_0 r^3}$和$E_\theta=\frac{p\sin\theta}{4\pi\epsilon_0 r^3}$。场按$1/r^3$衰减（比点电荷的$1/r^2$更快）——这是偶极子远近抵消效应导致的。

在MATLAB中可视化电偶极子：构造两个靠近的点电荷（$+q$和$-q$），计算每个空间点的总电场（两个电荷电场的矢量和）。近场区（$r\sim d$）图案复杂——场线从正电荷出发、弯曲绕向负电荷，形成标志性的"花生形"场线。远场区（$r\gg d$）图案简化为偶极子特征场——在赤道面（$\theta=90°$）上电场方向垂直于径向（纯$\theta$方向），在极轴上（$\theta=0°$或180°）电场方向沿径向。

电偶极子远场可视化的一个有趣现象：在不同$\theta$处电场方向不同——在极轴附近电场几乎沿径向向外，在赤道面附近电场几乎沿切向指向负电荷。MATLAB中可以通过quiver的箭头方向清楚展示这种角度依赖关系，也可以用streamline绘制从正电荷发出到负电荷终止的弯曲场线。
