# MATLAB 静电场可视化提示词 MOC

## 目录说明

本目录提供使用 MATLAB 可视化静电场核心概念的提示词，涵盖点电荷电场、电偶极子场、等位面等内容的可视化绘图代码框架。

## 可视化目标

- 点电荷的电场线 $$E = \frac{q}{4\pi\varepsilon_0 r^2}e_r$$ 和等位面 $$\Phi = \frac{q}{4\pi\varepsilon_0 r}$$
- 电偶极子的场分布：$$E_r = \frac{p\cos\theta}{2\pi\varepsilon_0 r^3}, E_\theta = \frac{p\sin\theta}{4\pi\varepsilon_0 r^3}$$
- 利用 meshgrid + quiver/streamline 绘制矢量场
- 利用 contour/contourf 绘制等位线/面

## MATLAB核心函数

| 函数 | 用途 |
|------|------|
| meshgrid | 生成2D/3D坐标网格 |
| quiver/quiver3 | 绘制矢量箭头图 |
| streamline | 绘制流线（电场线） |
| contour/contourf | 绘制等值线/面 |
| surf/mesh | 绘制3D曲面 |
| gradient | 数值梯度计算 |

## 扩展学习

### 更多教科书内容

本概念在电磁场与电磁波中有广泛的应用。位移电流 $$\frac{\partial D}{\partial t}$$ 是麦克斯韦方程组中最具创造性的部分，它将电场的变化与磁场的产生联系起来。坡印亭矢量 $$S = E \times H$$ 揭示了电磁能量的流动规律。时谐电磁场的复矢量方法将时间域的偏微分方程转化为频率域的代数方程，极大地简化了计算。

### 关键公式速览

| 公式 | 含义 | 所属章节 |
|------|------|----------|
| $\nabla \times H = J + \frac{\partial D}{\partial t}$ | 全电流定律 | §7-1 |
| $\nabla \times E = -\frac{\partial B}{\partial t}$ | 法拉第定律 | §7-2 |
| $S = E \times H$ | 坡印亭矢量 | §7-6 |
| $S_c = \dot{E} \times \dot{H}^*$ | 复能流密度 | §7-11 |
| $E_x = E_{x0}e^{-jkz}$ | 均匀平面波 | §8-2 |
| $\delta = \frac{1}{\sqrt{\pi f\mu\sigma}}$ | 集肤深度 | §8-3 |

### 常见考试错误提醒

1. 在时变场中忘记添加位移电流项 $$\partial D/\partial t$$
2. 混淆有效值和最大值（$$\dot{E}_m = \sqrt{2}\dot{E}$$）
3. 复能流密度计算时忘记取共轭：$$S_c = \dot{E} \times \dot{H}^*$$
4. 理想介质和导电介质的传播参数混淆
5. 边界条件的切向/法向分量搞错

## 费曼深度讲解

静电场的可视化核心在于展现两个物理特征：电场线的"发散"（由正电荷发出、终止于负电荷）和等位面的"正交"（电位相等的面处处与电场线垂直）。在MATLAB中，电场线通过quiver（2D）或quiver3（3D）绘制——每个箭头指向该点的电场方向，箭头的长度代表场强大小。等位面通过contour（2D）或isosurface（3D）绘制——每条/每层等位线/面连接电位相同的点。

点电荷电场的可视化是最基本的练习：$E = \frac{q}{4\pi\epsilon_0 r^2}\mathbf{e}_r$。在MATLAB中构造空间网格[X,Y,Z]，计算每个网格点到点电荷的距离$R$，然后计算电场分量$E_x = \frac{q}{4\pi\epsilon_0}\frac{X}{R^3}$等。关键在于：电场在靠近点电荷处发散（$1/r^2$奇点），所以可视化时需要设定合理范围（如$R > R_{min}$）避免数值溢出。

电偶极子的场分布是静电场可视化中最美的图案之一——对称的"花生形"场线。正电荷和负电荷各自的辐射状电场叠加后，形成了弯曲的场线从正电荷出发、经过空间曲线、最终抵达负电荷。等位面从近场的球形逐渐过渡到远场的更为复杂的形状——这种"近场复杂、远场似偶极子"的模式在MATLAB中通过调整绘图范围可以清晰展示。
