# MATLAB 提示词：点电荷电场线与等位面

## 教科书原文

> 📖 参见：[[§2-2 真空中的静电场]]

## 物理模型

点电荷 q 位于原点，空间电场：
$$E_x = \frac{q}{4\pi\varepsilon_0}\frac{x}{(x^2+y^2)^{3/2}}, \quad E_y = \frac{q}{4\pi\varepsilon_0}\frac{y}{(x^2+y^2)^{3/2}}$$

电位：$$\Phi(x,y) = \frac{q}{4\pi\varepsilon_0\sqrt{x^2+y^2}}$$

## MATLAB 实现提示词

```matlab
% 点电荷电场线与等位面可视化
% 参数设置
q = 1e-9;              % 电荷量 (C)
eps0 = 8.854e-12;      % 真空介电常数
k = 1/(4*pi*eps0);     % 库仑常数

% 生成2D网格
x = linspace(-2, 2, 50);
y = linspace(-2, 2, 50);
[X, Y] = meshgrid(x, y);

% 计算电场分量（避开原点奇点）
R = sqrt(X.^2 + Y.^2);
R(R < 0.01) = NaN;     % 避免除以零
Ex = k*q*X ./ R.^3;
Ey = k*q*Y ./ R.^3;
E_mag = sqrt(Ex.^2 + Ey.^2);

% 计算电位
Phi = k*q ./ R;

% 绘图
figure('Position', [100 100 1000 400]);

subplot(1,2,1);
% 电场线 (quiver) + 等位面 (contour)
quiver(X, Y, Ex./E_mag, Ey./E_mag, 0.5, 'b');
hold on;
contour(X, Y, Phi, 20);
axis equal; xlabel('x'); ylabel('y');
title('点电荷电场线(蓝)与等位线(彩色)');
```

## 关键可视化要素

| 要素 | MATLAB实现 | 物理含义 |
|------|-----------|----------|
| 电场线方向 | quiver(X,Y,Ex, Ey) | 径向向外(正电荷) |
| 电场线密度 | 归一化箭头 | 近区密、远区疏 (∝1/r²) |
| 等位线 | contour(X,Y,Phi) | 同心圆 |
| 正交性 | 电场线⊥等位线 | 梯度的几何性质 |

## 费曼深度讲解

点电荷的电场和图是最基本的静电场可视化练习——也是理解所有复杂场分布的基础。单个点电荷的电场是辐射状的（从正电荷向外、向负电荷向内），等位面是以电荷为球心的同心球面。电场线处处垂直于等位面——这是因为$E=-\nabla\varphi$，梯度方向（电场方向）是电位变化最快的方向，即等位面的法向。

在MATLAB中绘制时，一个关键参数是"电场强度截断"——由于$E\propto 1/r^2$，靠近点电荷处E值可以非常大（理论奇点），导致远场箭头小到不可见。解决方法：(1)设置最小距离$r_{min}$（排除太靠近点电荷的区域）；(2)使用对数颜色映射（log-scale colormap）来显示大跨度的场强变化；(3)对于箭头图，使用归一化箭头长度（所有箭头相同长度）配合颜色编码强度。

点电荷电场线的另一个教学价值是验证高斯定律：数一下穿过任意闭合球面的"电场线数量"（实际上看的是E在球面上的积分），你会发现在不同半径的球面上这个"数量"是恒定不变的——因为自由空间的介电常数下$\oint D\cdot dS = q$与球面半径无关。这就是$1/r^2$衰减与球面面积$4\pi r^2$增长恰好抵消的几何结果。
