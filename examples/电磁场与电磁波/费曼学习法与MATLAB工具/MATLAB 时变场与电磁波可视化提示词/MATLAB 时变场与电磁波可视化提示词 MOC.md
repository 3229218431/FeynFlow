## 扩展内容

### 时变电磁场可视化要点

时变电磁场的可视化比静态场复杂：场不仅是空间的函数，还是时间的函数。MATLAB中可以使用动画（animatedline, getframe, VideoWriter）来展示场的动态变化。

### 核心可视化函数

| 函数 | 用途 |
|------|------|
| animatedline | 动态绘制 |
| getframe + VideoWriter | 创建动画视频 |
| quiver3 | 3D矢量场 |
| surf | 3D曲面（如波的传播） |

### 可视化目标

1. **平面波E和H的动态传播**：展示TEM波中E和H的正交关系和传播过程
2. **趋肤深度演示**：展示导体中电磁波振幅的指数衰减
3. **极化动画**：展示线极化、圆极化波的E矢量端点轨迹

### 物理参数说明

在可视化时谐电磁场时，通常使用：$$E(z,t) = E_0 e^{-k''z}\cos(\omega t - k'z)$$，同时展示振幅衰减和相位传播。

## 费曼深度讲解

时变电磁场的可视化是电磁场学习中最令人兴奋但也最具挑战性的部分。静态场是"凝固的画面"——电场线和等位面一旦画出来就是固定的。时变场是"动态的电影"——电场和磁场随时间变化，互相耦合，在空间中传播。MATLAB的动画功能（如通过循环绘制不同时间帧然后用getframe和movie播放）让你能直观看到"电磁波是如何传播的"。

时变场可视化中最重要的概念是相位推进：在传播方向上，E和H的相位沿z轴线性推进（对平面波$e^{j(\omega t - kz)}$）。当你在MATLAB中逐帧更新$\omega t$，你会看到波形沿z方向移动——这就是"行波"。如果反射产生驻波（$e^{j\omega t}\cos(kz)$），你会看到振幅在空间上固定、时间上脉动的"驻波图案"。这两种行为在MATLAB动画中的视觉差异非常鲜明。

趋肤深度的可视化是理解时变场与导电介质相互作用的绝佳方式。在导体内，电磁波的振幅按$e^{-z/\delta}$指数衰减（$\delta$为趋肤深度），当$f$变大时$\delta$变小——高频电流只沿导体表面流动。用MATLAB绘制不同频率下电流密度的径向分布（$J(r) = J_0 e^{-(a-r)/\delta}$），你会直观理解为什么越高频越需要粗导线、为什么屏蔽罩在低频下几乎无效。

## 更多类比

MATLAB时变场可视化就像制作一部"电磁波纪录片"——每一帧是一张静态场分布图（用surf绘制E和H的振幅），所有帧按时间顺序播放就成了电磁波传播的动画。你可以放慢（降低频率）来观察E和H如何互相感应产生，也可以加快（提高频率）来观察趋肤效应和波长短缩。
