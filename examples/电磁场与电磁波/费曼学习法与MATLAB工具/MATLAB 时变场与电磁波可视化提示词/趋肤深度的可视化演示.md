# MATLAB 提示词：趋肤深度的可视化演示

请生成一段完整的、可运行的 MATLAB 代码，实现以下功能：

### 功能描述
展示平面电磁波从真空正入射到良导体表面的场分布。在导体内部 E 场振幅按 e^(-z/$delta$) 指数衰减。用动画或静态图清晰标注趋肤深度 $delta$ 的位置。

### 输入参数
- f: 频率，默认 1 MHz
- $sigma$: 电导率，默认 5.8e7（铜）
- z_range: 深度范围 [0, 5*$delta$]（5倍趋肤深度内衰减到接近零）
- E0: 入射波振幅，默认 1 V/m

### 输出要求
- 使用 subplot(2,1,1) 显示 E(z) 振幅的指数衰减包络线
- subplot(2,1,2) 显示 E(z,t) 在某时刻的瞬时波形
- 在图上标注 $delta$ 位置和 E0/e（≈37%）的水平线
- 用红色虚线标出 $delta$, 2delta, 3delta 位置
- 标注"在 z=5*$delta$ 处振幅降至表面值的 0.67%"
- 图形窗口 800×600

### 代码结构要求
1. clear all; close all; clc;
2. 参数定义区
3. 计算 $delta$ = sqrt(1/($pi$*f*$\mu_0$*$sigma$))
4. z = linspace(0, 5*$delta$, 200)
5. E_amplitude = E0 * exp(-z/$delta$)
6. subplot(2,1,1): plot 包络线 + 标注 $delta$
7. subplot(2,1,2): plot 衰减正弦波

### 注释要求
- 解释为什么 $delta$ ∝ 1/sqrt(f)
- 说明导体中 E 和 H 不再同相

### 错误处理
- 检查 $sigma$ > 0 和 f > 0

上方子图：指数衰减曲线从 z=0 处的 1 下降到 5*$delta$ 处接近 0，红线标注 37% 点。下方子图：衰减振荡波形展示振幅随深度递减。

### 更多教科书内容

本概念在电磁场与电磁波中有广泛的应用。位移电流 $$\frac{\partial D}{\partial t}$$ 是麦克斯韦方程组中最具创造性的部分，它将电场的变化与磁场的产生联系起来。坡印亭矢量 $$S = E \times H$$ 揭示了电磁能量的流动规律。时谐电磁场的复矢量方法将时间域的偏微分方程转化为频率域的代数方程，极大地简化了计算。

### 常见考试错误提醒

1. 在时变场中忘记添加位移电流项 $$\partial D/\partial t$$
2. 混淆有效值和最大值（$$\dot{E}_m = \sqrt{2}\dot{E}$$）
3. 复能流密度计算时忘记取共轭：$$S_c = \dot{E} \times \dot{H}^*$$
4. 理想介质和导电介质的传播参数混淆
5. 边界条件的切向/法向分量搞错

## 费曼深度讲解

趋肤深度（集肤深度）$\delta = 1/\sqrt{\pi f\mu\sigma}$是时变电磁场在导体中传播的最关键参数。它在物理上表示电磁波在导体内振幅衰减到表面值$1/e\approx 37\%$时的渗透深度。在MATLAB中可视化趋肤深度：固定z为传播方向进入导体，绘制$|E(z)| = |E_0|e^{-z/\delta}$的曲线——这是一条指数衰减曲线。改变频率f（如1kHz、1MHz、1GHz），你会看到$\delta$急剧缩小——在1MHz时铜的$\delta\approx 66\mu m$，在1GHz时仅约$2\mu m$。

为什么趋肤效应会导致交流电阻高于直流电阻？因为高频电流只在导体表面薄层内流动（有效导电截面积减小），而直流电流均匀分布在整个横截面内。这就像高速公路的拥堵——如果所有车可以同时在所有车道行驶（直流），容量最大；但如果只有最外侧车道能行驶（趋肤效应），有效通行量降低。在MATLAB中，用不同颜色绘制不同频率下的电流密度径向分布，可以直观展示这个效应。

趋肤深度的MATLAB可视化还有一个层面——对比良导体（铜）和不良导体（海水、大地）的趋肤深度。在相同频率下，铜的$\delta$远小于海水（因为$\sigma_{Cu}\gg\sigma_{seawater}$），这解释了为什么潜艇通信必须使用极低频（ELF，约76Hz）——只有足够低的频率才能使电磁波穿透海水到达潜艇。
