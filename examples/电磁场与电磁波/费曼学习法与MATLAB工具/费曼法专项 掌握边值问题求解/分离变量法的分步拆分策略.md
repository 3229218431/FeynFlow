# 分离变量法的分步拆分策略

## 概念/题目

分离变量法是求解静电场的边值问题的核心方法。其基本思想是：将多维偏微分方程分解为多个一维常微分方程，分别求解后叠加得到通解，最后由边界条件确定系数。

**核心方程（拉普拉斯方程）**：
$$\nabla^2 \varphi = 0$$

**分步策略**：

**步骤1：选择坐标系**。根据边界几何形状选择：矩形→直角坐标；圆柱→圆柱坐标；球形→球坐标。

**步骤2：写出拉普拉斯算符**。例如直角坐标系：
$$\frac{\partial^2\varphi}{\partial x^2} + \frac{\partial^2\varphi}{\partial y^2} + \frac{\partial^2\varphi}{\partial z^2} = 0$$

**步骤3：设分离变量形式** $\varphi(x,y,z) = X(x)Y(y)Z(z)$，代入得：
$$\frac{1}{X}\frac{d^2X}{dx^2} + \frac{1}{Y}\frac{d^2Y}{dy^2} + \frac{1}{Z}\frac{d^2Z}{dz^2} = 0$$

**步骤4：引入分离常数**。因三项之和为零，各项必为常数：
$$\frac{X''}{X} = -k_x^2,\quad \frac{Y''}{Y} = -k_y^2,\quad \frac{Z''}{Z} = k_x^2 + k_y^2$$

**步骤5：求解ODEs**，根据分离常数正负选择 sin/cos 或 sinh/cosh 或指数函数。

**步骤6：由边界条件确定系数**。利用惟一性定理保证解的唯一性。

## 费曼讲解

分离变量法就像一个分馅饼游戏。你有一个大馅饼（偏微分方程），但你不能一口吃掉。你的策略是：沿着x方向切一刀、y方向切一刀、z方向切一刀，把大馅饼变成三个小馅饼（常微分方程）。每个小馅饼你可以单独吃掉（单独求解），然后把三个味道叠加起来就恢复了原来的味道。最妙的是，这三刀必须配合好——切开的常数加起来必须为零（$k_x^2 + k_y^2 + k_z^2 = 0$），就像三个小朋友分一个披萨，必须刚好分完。

## 费曼深度讲解

分离变量法的分步拆分策略——把复杂的偏微分方程边值问题拆成7个步骤，逐个击破：(1)识别坐标系的适配性——边界面是否与坐标面吻合；(2)写出相应坐标系下的拉普拉斯方程；(3)假设分离变量形式$\varphi=X(x)Y(y)Z(z)$并代入，分离出三个常微分方程；(4)写出每个方向上的通解形式（三角函数/双曲函数/指数函数/贝塞尔函数/勒让德函数）；(5)施加齐次边界条件确定分离常数——这是最需要物理直觉的步骤（利用"正弦函数在x=0和x=a处为零→$k_x=n\pi/a$"的边界约束）；(6)写出满足齐次边界的特解（每个n一个解）；(7)将所有特解叠加以傅里叶级数展开，利用非齐次边界条件确定级数系数。

为什么第5步（确定分离常数）是最关键的？因为它把"数学方程"和"物理边界"真正连接了起来。分离常数不来自方程本身（方程只要求$k_x^2+k_y^2+k_z^2=0$），而来自边界条件的"强制"——例如要求在$x=0$和$x=a$处$\varphi=0$，这意味着$X(x)$必须在这两点为零，所以$X(x)\propto\sin(n\pi x/a)$，$k_x=n\pi/a$——分离常数值就是这样被边界"量子化"的。没有边界条件，分离常数可以取任意值；有了边界条件，分离常数只能取一系列离散值（特征值）。

第7步（傅里叶展开求系数）是"数学收尾"——利用三角函数的正交性，两边乘以$\sin(m\pi x/a)$（或其他正交基函数）并积分，左边只剩m=n的项（正交性使所有$m\neq n$项贡献为零），从而得到系数的显式表达式。正交集的选择取决于前序步骤得到的特征函数——直角坐标用三角函数，圆柱坐标用贝塞尔函数，球坐标用勒让德函数。

## 更多费曼检验

1. 在分离变量法的第5步中，如何判断分离常数应该取正还是取负？从"方向上有零点"→三角函数（负分离常数），"方向上有衰减"→双曲函数（正分离常数）。

2. 如果一个非齐次边界条件是常数$\varphi=V_0$（沿整个x边界），其傅里叶展开的系数是什么？提示：常数函数$\v_0$的傅里叶正弦级数展开系数为$a_n=4V_0/(n\pi)$（n为奇数）和0（n为偶数）。
