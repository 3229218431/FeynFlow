## 理想介质 vs 导电介质参数全对比

| 参数 | 符号 | 理想介质 σ=0 | 一般导电介质 | 良导体 σ≫ωε |
|------|------|-------------|-------------|------------|
| 传播常数 | k | $\omega\sqrt{\mu\varepsilon}$$ (实) | $k'-jk''$$ (复) | $(1-j)\sqrt{\pi f\mu\sigma}$ |
| 相位常数 | k' | $\omega\sqrt{\mu\varepsilon}$ | 见(8-3-9a) | $\sqrt{\pi f\mu\sigma}$ |
| 衰减常数 | k'' | 0 | 见(8-3-9b) | $\sqrt{\pi f\mu\sigma}$ |
| 相速 | v_p | $1/\sqrt{\mu\varepsilon}$ | $\omega/k'$ | $\sqrt{4\pi f/(\mu\sigma)}$ |
| 波长 | λ | $2\pi/k = v_p/f$ | $2\pi/k'$ | $2\pi\sqrt{2/(\omega\mu\sigma)}$ |
| 波阻抗 | Z | $\sqrt{\mu/\varepsilon}$$ (实) | \|Z_c\|∠φ (复) | $(1+j)\sqrt{\pi f\mu/\sigma}$ |
| 集肤深度 | δ | ∞ | $1/k''$ | $1/\sqrt{\pi f\mu\sigma}$ |
| E-H相位差 | Δψ | 0 | ∈(0,45°) | 45° |

## 真空中的数值

| 参数 | 公式 | 数值 |
|------|------|------|
| 光速 | $c = 1/\sqrt{\mu_0\varepsilon_0}$ | $3\times 10^8$$ m/s |
| 波阻抗 | $Z_0 = \sqrt{\mu_0/\varepsilon_0}$ | $120\pi \approx 377\Omega$ |
| $f=1\text{GHz}$$ 波长 | $\lambda_0 = c/f$ | 0.3 m |
| $f=3\text{GHz}$$ 波长 | $\lambda_0 = c/f$ | 0.1 m |

## 计算流程

```
已知 f, ε_r, μ_r, σ
    │
    ├→ 计算 σ/(ωε) 判据
    │
    ├→ 理想介质分支: k=ω√με, v_p=1/√με, Z=√μ/ε, λ=v_p/f
    │
    ├→ 良导体分支: k'=k''=√πfμσ, δ=1/√πfμσ, Z_c=(1+j)√πfμ/σ
    │
    └→ 一般有耗: 使用完整公式(8-3-9)
```

## 扩展学习

### 更多教科书内容

本概念在电磁场与电磁波中有广泛的应用。位移电流 $$\frac{\partial D}{\partial t}$$ 是麦克斯韦方程组中最具创造性的部分，它将电场的变化与磁场的产生联系起来。坡印亭矢量 $$S = E \times H$$ 揭示了电磁能量的流动规律。时谐电磁场的复矢量方法将时间域的偏微分方程转化为频率域的代数方程，极大地简化了计算。

### 关键公式速览

| 公式 | 含义 | 所属章节 |
|------|------|----------|
| $\nabla \times H = J + \frac{\partial D}{\partial t}$ | 全电流定律 | §7-1 |
| $\nabla \times E = -\frac{\partial B}{\partial t}$ | 法拉第定律 | §7-2 |
| $S = E \times H$ | 坡印亭矢量 | §7-6 |
| $S_c = \dot{E} \times \dot{H}^*$ | 复能流密度 | §7-11 |
| $E_x = E_{x0}e^{-jkz}$ | 均匀平面波 | §8-2 |
| $\delta = \frac{1}{\sqrt{\pi f\mu\sigma}}$ | 集肤深度 | §8-3 |

### 常见考试错误提醒

1. 在时变场中忘记添加位移电流项 $$\partial D/\partial t$$
2. 混淆有效值和最大值（$$\dot{E}_m = \sqrt{2}\dot{E}$$）
3. 复能流密度计算时忘记取共轭：$$S_c = \dot{E} \times \dot{H}^*$$
4. 理想介质和导电介质的传播参数混淆
5. 边界条件的切向/法向分量搞错

## 费曼深度讲解

平面波参数对照表是考前5分钟最值得看的"终极速查"——因为它把理想介质、良导体和一般导电介质中的6个关键参数（k/γ、λ、v_p、η、α、β）按介质类型分别列出。助记线索：理想介质中α=0（无衰减），v_p=c/n（折射率控制速度），η=η_0/√(ε_r)（实数波阻抗）。良导体中α=β=√(πfμσ)=1/δ（衰减和相位常数相同），v_p=√(4πf/(μσ))（远比光速慢），η=(1+j)√(πf/μ)/σ（45°相位差）。

为什么理想介质中电场能量密度等于磁场能量密度（w_e=w_m）？从坡印亭定理可以导出：在无损耗的时谐场中，平均电场储能和平均磁场储能相等。从平面波解看：w_e=εE²/4，w_m=μH²/4，而H=E/η，η=√(μ/ε)，代入得w_m=μE²/(4η²)=μE²ε/(4μ)=εE²/4=w_e。能量均分——这是电磁波与弹簧振子（动能=势能）在物理本质上的类似性。

一般导电介质的过渡频率σ/(ωε)是判断介质类别的关键：当σ/(ωε)≪1（高频或良介质极限）→近似理想介质；当σ/(ωε)≫1（低频或良导体极限）→近似良导体；当σ/(ωε)≈1→一般导电介质，需要完整的复数表达式。
