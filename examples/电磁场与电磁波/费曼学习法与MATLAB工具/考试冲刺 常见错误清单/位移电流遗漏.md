# 常见错误：忘记添加位移电流项

## 错误描述

学生在应用安培环路定律解题时，经常**忘记在时变场中添加位移电流项** $$\partial D/\partial t$$，直接使用静态场形式 $$\nabla \times H = J$$。

## 教科书原文

> 📖 参见：[[§7-1 位移电流]]

## 错误表现

### 错误写法
$$\nabla \times H = J$$（只考虑了传导电流）

### 正确写法
$$\nabla \times H = J + \frac{\partial D}{\partial t}$$

## 何时不能忽略位移电流？

| 场景 | 能否忽略 ∂D/∂t | 原因 |
|------|:---:|------|
| 静态场 | 能 | $\partial D/\partial t = 0$ |
| 低频电路 (50Hz) | 通常能 | 位移电流远小于传导电流 |
| 电容器内部 | **不能** | 传导电流=0，位移电流是唯一磁场源 |
| 高频/微波 | **不能** | 频率高→位移电流增大 |
| 电磁波传播 | **不能** | 位移电流是电磁波存在的必要条件 |
| 不良导体中 | **不能** | $\sigma/\omega\varepsilon \ll 1$$时位移电流>传导电流 |

## 电容器充电悖论（经典考点）

同一安培环路，以导线为边界 → $$I_{cond} \neq 0$$；以电容器间隙为边界 → $$I_{cond} = 0$$。矛盾！加上位移电流后：通过间隙的位移电流 = 通过导线的传导电流，全电流连续性恢复。

## 考试易错题

**题**：真空中 $$B(t) = e_y 10^{-3}\sin(6\pi\times 10^8 t - kz)$$ T，求位移电流密度。

**错解**：直接算 $$J = 0$$（真空无传导电流）

**正解**：$$\nabla \times H = J_d$$（真空无传导电流），$$H = B/\mu_0$$ → $$J_d = \nabla \times (B/\mu_0)$$，算出 $$J_d = e_x \frac{k}{\mu_0}10^{-3}\cos(6\pi\times 10^8 t - kz)$$

> 传导之外加位移，全电流才连续理。

## 费曼深度讲解

位移电流遗漏是时变电磁场计算中最常见的致命错误。根本原因：安培原始的环路定律$\nabla\times H=J$只适用于恒定电流（电荷分布不随时间变化），在时变情况下$\nabla\cdot J$不再是零（时变电荷需要满足电荷守恒），所以必需在方程右边加上$\partial D/\partial t$（位移电流密度），使得修正后的方程$\nabla\times H=J+\partial D/\partial t$能满足$\nabla\cdot(\nabla\times H)=0=\nabla\cdot J+\partial(\nabla\cdot D)/\partial t=\nabla\cdot J+\partial\rho/\partial t$——这正是电荷守恒方程。

什么场景下最容易忘记位移电流项？(1)平板电容器中的时变电场——极板间没有传导电流但存在$\partial D/\partial t$，它产生与传导电流同样效果的磁场；(2)电磁波辐射问题——恒定的J产生恒定的H，但只有$\partial D/\partial t$才能使H也有时变性，两者耦合才能产生传播的电磁波；(3)位移电流不仅是"补救"安培定律的数学缺失——它是电磁波存在的物理基础。没有位移电流项，麦克斯韦方程组退化为四个解耦的静电场+静磁场方程，没有电磁波。

自检方法：每当你使用安培定律时，问自己："电流密度J是否满足恒定条件$\nabla\cdot J=0$？电荷分布是否随时间变化？"如果答案是"不满足"或"是"，必须加上位移电流项$\partial D/\partial t$。如果不确定，加上它总是对的——因为麦克斯韦的全电流方程在恒定条件下自动退化（$\partial D/\partial t=0$）。
