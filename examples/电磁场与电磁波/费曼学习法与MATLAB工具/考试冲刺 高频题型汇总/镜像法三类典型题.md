# 高频题型：镜像法三类典型题

## 题型概述

镜像法用于求解**无限大导体平面**（或介质平面）附近有点电荷/线电荷时的电场分布。核心思想是用**镜像电荷**代替导体表面的感应电荷，使问题转化为多个点电荷在无界空间中的场叠加。

## 第一类：无限大导体平面附近的点电荷

**问题**：无限大接地导体平面上方 h 处有点电荷 q，求上方空间的电场。

**镜像法**：
- 镜像电荷：在导体平面下方 h 处（对称位置）放置 -q
- 去掉导体平面
- 上方空间电场 = q 和 -q 在无界空间中的叠加

**关键结果**：
- 导体表面感应电荷密度：$$\rho_S = -\frac{qh}{2\pi(h^2+\rho^2)^{3/2}}$$
- 总感应电荷：-q（等于镜像电荷）
- 点电荷受到的吸引力：$$F = \frac{q^2}{4\pi\varepsilon_0(2h)^2}$$

## 第二类：接地导体球附近的点电荷

**问题**：半径为 a 的接地导体球外距离球心 d 处有点电荷 q。

**镜像法**：
- 镜像电荷 $$q' = -\frac{a}{d}q$$，位于球内距离球心 $$b = a^2/d$$ 处
- 去掉导体球
- 球外电场 = q 和 q' 的叠加

## 第三类：介质平面界面附近的点电荷

**问题**：两种介质（ε₁ 和 ε₂）平面界面上方 h 处有点电荷 q（在 ε₁ 中）。

**镜像法**：
- 求 ε₁ 中电场：在界面下方 h 处放置镜像电荷 $$q' = \frac{\varepsilon_1-\varepsilon_2}{\varepsilon_1+\varepsilon_2}q$$
- 求 ε₂ 中电场：去掉 q，在上方 h 处放置等效电荷 $$q'' = \frac{2\varepsilon_2}{\varepsilon_1+\varepsilon_2}q$$

## 镜像法三步解题法

1. **确定镜像**：根据边界类型确定镜像电荷的位置、大小和符号
2. **验证边界条件**：确认镜像方案使原边界条件得到满足
3. **求场**：用无界空间中电荷系的场叠加公式计算

## 费曼深度讲解

镜像法三类经典题型覆盖了考试中90%以上的镜像法考点：(1)点电荷+接地导体平面→镜像电荷-q在对称位置，总电场=原电荷+镜像电荷。求解区域的电位$\varphi=\frac{q}{4\pi\epsilon_0}(\frac{1}{r_1}-\frac{1}{r_2})$。感应面电荷密度$\sigma_s = -\epsilon_0\frac{\partial\varphi}{\partial n}|_{surface} = \frac{-qh}{2\pi(h^2+\rho^2)^{3/2}}$（h为电荷到面距离）。注意：镜像电荷不能用于计算导体表面的感应电荷总电量Q=+q的场（镜像在背面！），但可以通过$\oint\sigma_s dS = -q$积分验证——总面积电荷为-q=镜像电荷量；(2)点电荷+接地导体球→镜像电荷$q'=-\frac{a}{d}q$放置在距球心$\frac{a^2}{d}$处（d为原电荷距球心距离，a为球半径），解区域为球外；(3)点电荷+介质界面（半无限大介质）→在介质1侧加镜像$q'=q\frac{\epsilon_1-\epsilon_2}{\epsilon_1+\epsilon_2}$，在介质2侧出现"透射电荷"$q''=q\frac{2\epsilon_2}{\epsilon_1+\epsilon_2}$。

镜像法的最大误区——镜像电荷不能"越界"：(1)镜像电荷不能放置在你关心的求解区域内（如在导体后方放镜像，导体前方是求解区域）；(2)导体表面感应电荷对导体内部无场（静电屏蔽——导体内部场为零），所以镜像产生的场只在导体外部有意义；(3)球形镜像问题中，镜像电荷在球内（不在求解区域球外），所以球外场的计算有效。

为什么不同类型（平面、球、介质界面）的镜像系数不同？源自边界条件的几何形状对"等效位置"和"等效电荷量"施加的约束。接地导体平面要求整个无限大平面等位（零位），这只需要位置对称、电荷反号的一个镜像电荷（完美对称）。接地导体球要求球面等位（零位），镜像不再是对称位置而是"反演位置"（$d'=a^2/d$），电荷量也需缩放（$q'=-qa/d$）。介质界面要求界面上的切向E和法向D连续——两个边界条件决定了两个未知量（镜像电荷量和透射电荷量）。
