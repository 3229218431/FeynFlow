# MATLAB 提示词：圆环电流磁力线分布

请生成一段完整的、可运行的 MATLAB 代码，实现以下功能：

### 功能描述
计算并绘制一个圆形电流环在空间中产生的磁场分布。用 quiver3 显示磁通密度 B 的矢量场，展示磁力线从圆环一侧穿出、绕到另一侧穿回（形成闭合环路）。

### 输入参数
- R: 圆环半径，默认 1 m
- I: 电流，默认 1 A
- x_range, y_range, z_range: 默认 [-2, 2]，步长取决于网格密度

### 输出要求
- 用 quiver3 绘制磁场矢量
- 在空间中标记圆环位置（用 plot3 绘制圆）
- 用 streamslice 或 coneplot 显示磁力线轨迹
- 颜色基于 |B| 的大小
- 使用 view(45, 30) 视角
- 图形窗口 800×700

### 代码结构要求
1. clear all; close all; clc;
2. 定义圆环参数和网格
3. 使用毕奥-萨伐尔定律数值积分计算每点的 B
4. quiver3 绘制矢量箭头
5. 叠加磁力线轨迹

### 注释要求
- 解释为什么磁力线永远是闭合的（∇·B=0）
- 说明圆环轴线上 B 方向的右手定则

### 错误处理
- 避免计算圆环线本身位置（r=0 奇点）

### 示例预期输出
3D 图中磁力线从圆环一侧（北方）向上弯曲再绕到另一侧（南方），形成闭合环形。圆环中心区域的磁场强度最大。命令行显示轴线上 B = μ₀IR²/[2(R²+z²)^(3/2)]。

### 常见考试错误提醒

1. 在时变场中忘记添加位移电流项 $$\partial D/\partial t$$

## 费曼深度讲解

圆环电流是恒定磁场中最经典的非直线电流结构。它的磁力线不是简单的圆形——在环面内，磁力线从圆环的一侧穿过环面到另一侧，在环外弯曲闭合。比奥-萨伐尔定律$B = \frac{\mu_0}{4\pi}\int \frac{Idl \times e_R}{R^2}$的数值计算告诉我们在任何空间点B的精确值和方向。轴线上（圆环中心轴），磁场的解析解$B_z = \frac{\mu_0 I a^2}{2(a^2+z^2)^{3/2}}$告诉我们磁场在环心处最强（$B(0)=\mu_0 I/2a$），随离开环面的距离按$1/(a^2+z^2)^{3/2}$衰减。

MATLAB中数值实现的关键是将圆环离散为N个电流元$Idl$。电流元的方向沿圆环切向，在球坐标系中不直观但在直角坐标系中很容易表达：$\phi$从0到$2\pi$均匀取N点，第$i$段电流元的坐标$(a\cos\phi_i, a\sin\phi_i, 0)$，方向$dl_i = a\Delta\phi(-\sin\phi_i \mathbf{e}_x + \cos\phi_i \mathbf{e}_y)$。然后对每个空间点$(x_j, y_j, z_j)$遍历所有电流元，计算$dB = \frac{\mu_0}{4\pi}\frac{Idl_i \times R_{ij}}{|R_{ij}|^3}$然后累加。

磁力线的可视化验证了$\nabla\cdot B=0$——每一条磁力线都是闭合曲线，没有起点也没有终点。使用streamline从环形区域的不同起始点追踪磁力线，你会看到磁力线从圆环的一侧（类似N极）发出，在空间中弯曲绕行，最终回到圆环的另一侧（类似S极），穿过环面再从另一侧出发——形成完整的闭合回路。
