## 扩展内容

### MATLAB矢量场可视化核心方法

可视化矢量场的三种基本方法：

1. **箭头图 (quiver/quiver3)**：每个网格点画一个矢量箭头
   - 优点：直观显示方向
   - 缺点：密集区域箭头重叠

2. **流线图 (streamline/streamslice)**：追踪矢量场中的路径
   - 优点：清晰显示场线走向
   - 缺点：需要指定起始点

3. **锥体图 (coneplot)**：3D中的锥形矢量表示
   - 优点：同时显示方向和大小
   - 缺点：计算量大

### 关键函数速查

| 函数 | 用途 | 典型调用 |
|------|------|----------|
| meshgrid | 生成2D网格 | [X,Y] = meshgrid(x,y) |
| ndgrid | 生成3D网格 | [X,Y,Z] = ndgrid(x,y,z) |
| quiver | 2D箭头图 | quiver(X,Y,U,V) |
| quiver3 | 3D箭头图 | quiver3(X,Y,Z,U,V,W) |
| streamline | 流线 | streamline(X,Y,U,V,sx,sy) |
| surf | 3D曲面 | surf(X,Y,Z) |
| contour | 等值线 | contour(X,Y,Z) |
| gradient | 数值梯度 | [FX,FY] = gradient(F) |

### 在电磁场中的应用

- **静电场**：quiver + contour 绘制电场线和等位面
- **恒定磁场**：streamline + quiver3 绘制磁力线
- **时变电磁场**：动画+surf 展示波传播

## 费曼深度讲解

矢量场可视化的核心挑战是一图要传达两个信息：方向和大小。quiver在2D中是一个绝佳工具箱——每个点一个箭头，方向即场方向，长度即场大小。但当场强变化幅度很大时（如$1/r^2$衰减的电场），简单的长度比例会让近源处的箭头过长溢出、远源处的箭头短不可见。解决方法是使用归一化箭头（所有箭头相同长度，方向不变）配合颜色映射（用颜色表示大小）——方向用箭头，大小用颜色，两者分离互不干扰。

streamline（流线）绘制的是"贯穿场的一条路径"——从某个起始点出发，沿着场的方向一步一步前进，走过的路径就是一条流线。这与磁力线和电场线的概念完全一致。在MATLAB中，streamline函数接受一个矢量场[X,Y,Z]和初始点，自动追踪场的方向绘制流线。多条流线从不同起点出发，经不同的"旅程"，共同构成了场的"交通地图"。

3D矢量场的挑战在于深度感知——在2D屏幕上展示3D空间中的箭头方向。quiver3通过透视效果在一定程度上解决了这个问题，但大量箭头在3D中容易互相遮挡、难以分辨。streamline3在3D中更有效——几条精心选择的流线能立刻传达3D场的结构和拓扑，就像"现场骨架"一样清晰。slice（切片）技术也很有效——取几个关键截面的流线和颜色图，牺牲"全貌"换取"清晰"。
