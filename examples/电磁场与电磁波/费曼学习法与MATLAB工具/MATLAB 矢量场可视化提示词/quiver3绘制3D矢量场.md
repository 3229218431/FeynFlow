# MATLAB 提示词：quiver3 绘制 3D 矢量场

请生成一段完整的、可运行的 MATLAB 代码，实现以下功能：

### 功能描述
用 quiver3 在三维空间中绘制矢量场 F = (x, y, z)，直观展示散度源（∇·F = 3，处处为正源）。同时绘制第二个矢量场 G = (-y, x, 0) 展示旋转场（∇×G ≠ 0）。

### 输入参数
- x_range, y_range, z_range: 默认 [-2, 2]，步长 1
- scale: 箭头缩放因子，默认 0.5

### 输出要求
- 使用 subplot(1,2,1) 显示散度场 F，subplot(1,2,2) 显示旋转场 G
- 使用 quiver3，箭头颜色用曲线颜色映射（基于矢量大小）
- 添加 colorbar、坐标轴标签、title
- 图形窗口尺寸 1200×500
- 使用 view(45, 30) 设置有利视角

### 代码结构要求
1. clear all; close all; clc;
2. 参数定义区
3. meshgrid 生成 3D 网格
4. 定义矢量场分量 (Fx,Fy,Fz) 和 (Gx,Gy,Gz)
5. quiver3 绘制 + colorbar
6. 计算并 disp 散度/旋度值

### 注释要求
- 解释为什么 quiver3 的第4-6个参数是方向分量
- 说明 meshgrid 的三个输出含义

### 错误处理
- 检查 x_range 是否为升序

### 示例预期输出
左侧：箭头从原点向外辐射（源场），颜色暖色表示箭头长。右侧：箭头绕 z 轴旋转（旋转场），在 xy 平面上形成环形。命令行显示 ∇·F = 3, ∇×G = (0,0,2)。

## 费曼深度讲解

quiver3是MATLAB中将3D向量场可视化的核心工具。它的六参数输入(X,Y,Z,U,V,W)同时定义了空间位置（X,Y,Z为网格坐标）和向量分量（U,V,W为该点的向量三个分量）。quiver3在3D中绘制每个网格点上的箭头——箭头的起点在(X,Y,Z)，方向沿(U,V,W)，长度代表向量大小。关键是网格不能太密（否则箭头堆叠成"刷子毛"看不清）也不能太疏（否则丢失空间细节）——通常5-20个点/维度是合理的折中。

3D矢量场与2D的一个关键区别是透视和遮挡。在3D中，远处的箭头因为透视变小，被近处箭头遮挡——MATLAB的rotate3d功能允许你旋转视角解决遮挡问题。另一个技巧是使用切片（slice）+ quiver3组合——在几个关键截面上绘制quiver3，不同截面的箭头用不同颜色区分——兼顾了空间全貌和局部细节。

在电磁场中，quiver3的典型应用包括：(1)绘制点电荷阵列的3D电场——每个箭头从正电荷向外辐射、向负电荷汇聚；(2)绘制圆环电流的3D磁场——箭头在环内沿轴向、在环外弯曲闭合；(3)绘制电磁波的3D E和H场——E箭头沿一个方向振动、H箭头沿垂直方向振动、两者沿传播方向以不同颜色绘制。
