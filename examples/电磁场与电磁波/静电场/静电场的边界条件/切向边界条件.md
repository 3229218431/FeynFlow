# 切向边界条件：E₂ₜ = E₁ₜ
**关键词**：边界条件, D法向, E切向, ρₛ, 介质分界面

📌 **一句话本质**：电场过界面时，切向E连续，法向D跳变

🏷️ **重要度**：🔴 | 考试：★★★ | 题型：计

🔧 **工程/实际场景**：手机触摸屏的ITO导电层与玻璃界面的切向E连续性决定了触摸感应电场的均匀度——如果切向边界条件搞反，触摸位置计算会偏移导致触控漂移；射频PCB微带线的介质-空气界面上切向E连续条件决定特征阻抗——算错会导致阻抗不匹配信号全反射

## 🧠 类比与直觉

**"游泳过河"类比**：想象你在游泳过一条水流方向平行河岸的河。不管你从哪侧下水，沿河岸方向（切向）你感受到的水流推力是一样的——这就是切向E连续。但垂直河岸的深浅（法向）两侧不同——这就是法向D跳变。

**"磁带到磁盘"类比**：两种介质界面就像磁带到磁盘的过渡——沿界面滑动方向（切向）摩擦力连续，但垂直按压的力（法向）不连续，因为两种材料硬度不同。

**口诀**："切向E连续，法向D跳变"

## 切向边界条件的本质

切向边界条件 $\mathbf{E}_{1t} = \mathbf{E}_{2t}$ 可以从法拉第定律直接推导。在介质分界面上取一狭长矩形环路（长边平行界面），当矩形高度趋于零时，垂直边的贡献消失：
$$\oint \mathbf{E}\cdot d\mathbf{l} = E_{1t}\Delta l - E_{2t}\Delta l = -\frac{\partial}{\partial t}\int\mathbf{B}\cdot d\mathbf{S} \to 0$$
因此 $E_{1t} = E_{2t}$。

对于磁场的切向边界条件：$\mathbf{n}\times(\mathbf{H}_1 - \mathbf{H}_2) = \mathbf{J}_s$

## 费曼深度讲解

切向边界条件$E_{1t}=E_{2t}$的物理来源是$\nabla\times E=0$（静电场保守性）的积分后果。证明方法：在介质界面处做一个非常"扁"的矩形闭合回路（高度h→0，长度Δl沿界面），沿该回路的环量$\oint E\cdot dl = E_{1t}\Delta l - E_{2t}\Delta l$（上下水平段）加上两个竖直段（h→0时贡献为零）。由于$\oint E\cdot dl = 0$（无旋场），得到$E_{1t}=E_{2t}$。关键理解：证明依赖回路的高度h→0使其竖直段的贡献消失——这要求h必须远小于界面的曲率半径和任何非均匀尺度。

为什么D的切向分量不连续？因为$D_{1t}/\epsilon_1 = E_{1t} = E_{2t} = D_{2t}/\epsilon_2$，所以$D_{1t}/D_{2t}=\epsilon_1/\epsilon_2$。介电常数大的介质一侧的切向D分量更大——但E的切向分量在两侧相等。这就是为什么电场线从高介电常数介质进入低介电常数介质时，切向分量不变而法向分量改变——电场线向法线方向折射。

切向边界条件在导体表面的特殊重要性：理想导体内部E=0→导体表面外$E_{1t}=E_{2t}=0$——导体外的电场垂直于导体表面。如果不是垂直的（有切向电流分量），那就在导体表面产生了切向电场，会在导体内驱动电流，但理想导体内部电场必须为零（否则无穷大电流），矛盾。所以电场线必须垂直入射导体表面。
