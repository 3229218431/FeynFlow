# 球坐标系分离变量法典型例题分析
**关键词**：分离变量法, 拉普拉斯方程, 级数解, 边界条件

## 概念/题目

**典型例题**：半径为 $a$ 的接地导体球置于均匀外电场 $E_0 = E_0 e_z$ 中。求球外的电位分布。

解：设球心在原点，外电场沿 $z$ 方向。球外电位满足拉普拉斯方程。轴对称解的通式：
$$\varphi(r,\theta) = \sum_{n=0}^{\infty}\left(A_n r^n + B_n r^{-(n+1)}\right)P_n(\cos\theta)$$

边界条件：
1. $r \to \infty$：$\varphi \to -E_0 z = -E_0 r\cos\theta = -E_0 r P_1(\cos\theta)$
2. $r = a$：$\varphi = 0$（接地）

由条件1：$A_1 = -E_0$，其余 $A_n = 0$（$n\neq 1$）

由条件2：$(-E_0 a + B_1 a^{-2})P_1(\cos\theta) + \sum_{n\neq 1} B_n a^{-(n+1)}P_n(\cos\theta) = 0$

由于勒让德多项式正交性，各项系数必须分别为零：
$B_1 = E_0 a^3$，其余 $B_n = 0$（$n\neq 1$）

最终解：
$$\varphi(r,\theta) = -E_0 r\cos\theta + E_0\frac{a^3}{r^2}\cos\theta = -E_0\left(r - \frac{a^3}{r^2}\right)\cos\theta$$

**物理意义**：第一项是外加均匀场，第二项是导体球感应出的电偶极子场——等效于球心处有一个电偶极矩 $p = 4\pi\varepsilon_0 a^3 E_0$。

## 费曼讲解

在均匀电场中放一个金属球，球的表面会产生感应电荷，整个球的作用相当于一个电偶极子。球坐标的分离变量法优雅地把这个物理事实提取了出来——通解中唯一活下来的项是 $n=1$（偶极子项）。这就是数学和物理的完美结合：勒让德多项式 $P_1(\cos\theta) = \cos\theta$ 恰好就是偶极子的形状。

## 费曼深度讲解

### 从零开始构建直觉

学习电磁场最忌讳的就是"先把公式背下来再说"。费曼的学习方法告诉我们：**先有直觉，后有公式**。公式只是直觉的数学翻译。

以本章内容为例：在翻开教科书之前，先想象你手里有一个可以"看见"电场和磁场的魔法眼镜。戴上这副眼镜后，你会看到空间中到处充满了看不见的"力线"：
- 正电荷周围，力线向外辐射（像刺猬的刺）
- 磁铁周围，力线从N极出发到S极，在内部闭合
- 变化的磁场周围，力线是闭合的漩涡

所有的公式——∇·D=ρ、∇×E=0、∇×H=J——都是这些视觉图像的精确数学描述。

### 三种理解层次

费曼提出，对一个概念的理解有三个层次：

**第一层——符号层**：能写出公式，会套公式计算。例如知道 ∇×E=0 表示"电场旋度为零"。

**第二层——直觉层**：能不用公式解释概念。例如："旋度为零意味着你沿着任何闭合路径走一圈，电场对你做的净功为零——就像在一个没有漩涡的湖里划船，绕岛一圈回到原点，顺流逆流恰好抵消。"

**第三层——创造层**：能根据直觉预测新情况。例如："既然旋度为零，那电场一定可以写成某个标量函数的梯度 E=-∇φ。如果这个标量函数在边界上固定了，内部的场也就唯一确定了——这就是唯一性定理。"

大多数学生停留在第一层，考试能过但遇到新问题就无从下手。**本笔记的目标是帮你达到第二层，向第三层迈进。**

### 如何检验自己的理解

每次学完一个概念后，做下面这个测试：
1. 合上笔记本
2. 找一张白纸
3. 用大白话写出这个概念的核心思想（不许用任何数学符号！）
4. 画一幅图表示这个概念
5. 想一个生活中类似的例子

如果第3步卡住了，说明你还没有真正理解——回去重新看类比和直觉部分。如果第5步做出来了，恭喜你，你已经超越90%的同学。

### 公式记忆的核心技巧

不要死记公式，要记住**推导的故事线**：
- ∇·D=ρ：高斯定律——"流出封闭面的总量=内部源的产量"（散度定理+库仑定律）
- ∇×E=0：静电场保守性——"走一圈不做功"（源自1/r² 力的中心对称性）
- ∇×H=J：安培定律——"电流周围磁场旋转"（比奥-萨伐尔定律的微分形式）
- ∇·B=0：磁通连续性——"磁力线没有起点和终点"（实验事实）

**每个公式背后都有一个物理故事。记住了故事，公式自然就记住了。**

## 费曼深度讲解

球坐标分离变量法的典型例题展示了从问题建模到最终解的全流程。经典题一：接地导体球壳放在均匀外电场中——计算球内外电位分布和球表面的感应电荷分布。求解步骤：(1)外电场在球坐标中写为渐近形式$\varphi\rightarrow -E_0 r\cos\theta$（r→∞）；(2)利用轴对称性（问题不涉及Φ坐标），解的形式为$\varphi(r,\theta)=\sum_{l=0}^{\infty}(A_l r^l+B_l r^{-(l+1)})P_l(\cos\theta)$；(3)施加边界条件：r=a处φ=0（接地球壳），r→∞处φ→-E_0 r cosθ；两个条件确定所有系数——结果只有l=1项非零：$\varphi=-E_0(r-\frac{a^3}{r^2})\cos\theta$（球外），$\varphi=0$（球内，静电屏蔽）。球表面的感应电荷密度$\sigma_s|_{surface}=-\epsilon_0(\partial\varphi/\partial r)|_{r=a}=3\epsilon_0 E_0\cos\theta$——在迎风面（θ=0）为负电荷最大密度，在背风面（θ=π）为正电荷最大密度，在赤道（θ=π/2）为中性线。

经典题二：均匀带电介质球（半径a，介电常数ε₁）放在无界的介质（ε₂）中——注意不是导体球壳问题。利用分离变量法求解球内外的电位分布，施加界面处的边界条件——r=a处$\varphi_1=\varphi_2$（电位连续）和$\epsilon_1\frac{\partial\varphi_1}{\partial r}=\epsilon_2\frac{\partial\varphi_2}{\partial r}$（法向D连续，界面无自由电荷）。结果：球内电场是均匀的且与外电场成相同方向，$E_1=\frac{3\epsilon_2}{\epsilon_1+2\epsilon_2}E_0$（球内极化场）。球外场是均匀外场+中心偶极子场之叠加——这是极化介质球散射外电场的经典解。
