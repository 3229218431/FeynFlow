# AI 费曼导师使用指南
**关键词**：电磁场与电磁波

## 这个知识库是什么

这是一个为 **AI辅助费曼式交互学习** 优化的电磁场与电磁波知识库。包含 300+ 篇笔记，覆盖教科书第1章至第8章第3节（考试范围）。

每篇笔记面向AI检索优化：YAML元数据、Wiki链接、Mermaid图表、MATLAB提示词。

## AI导师的四步教学法

按照费曼学习法与智能助手提示词，AI导师应遵循：

### 第一步：接收概念
用户提出想学的概念 → AI在知识库中搜索 `[[概念名]]` 笔记

### 第二步：简单解释
用笔记中的「类比与直觉」部分，以生活化比喻讲解（禁用专业术语）

### 第三步：盲点检验
用笔记中的「费曼检验」问题测试理解，或读取同章「思考题」文件

### 第四步：深入简化
根据用户盲点，阅读笔记中的「教科书推导」部分逐层深化

## 给用户的提示词模板

### 开始学习某概念
```
请用费曼学习法教我 [[梯度]]。先用生活类比讲清楚，再逐步推导公式。
所有知识以知识库中的笔记为准，不引入额外的内容。
```

### 做课后习题
```
请帮我理解这道题：[[第2章习题]] 中的 2-4。
先读题，再说清楚用了哪个概念，最后逐步推导。
不要直接给答案——引导我自己做出来。
```

### 自测理解程度
```
请从 [[矢量分析 思考题]] 中随机出3道题考我。
我回答后，根据我的回答找出理解盲区，针对性地重新讲解。
```

### MATLAB可视化
```
请根据 [[点电荷电场线与等位面]] 中的MATLAB提示词，生成完整的可运行代码。
代码要有详细中文注释，解释每步为什么这样做。
```

## MOC文件的使用

每个H3文件夹下的 `MOC.md` 是该主题的导航索引。MOC中包含：
- 学习状态勾选框 `- [ ]` （学完打勾）
- 所有原子笔记的Wiki链接（点击跳转）
- 概念导航（前置/后续/关联）

在Obsidian中按 `Ctrl+O` 搜索MOC可快速定位到任何主题。

## 每日学习流程

1. 打开 [[每日费曼学习日志模板]] 准备
2. 看该节「思考题」（预习，带着问题学）
3. 读概念笔记（费曼类比→公式→推导→误区）
4. 回答「费曼检验」自测题
5. 做「习题」
6. 填写学习日志（用自己的话复述今天学的）

## 配合AI导师的检索技巧

在Obsidian中：
- `[[概念名]]` = 跳转到该笔记
- 图谱视图 = 可视化知识网络
- `Ctrl+P` 命令面板 = 快速搜索
- Dataview 插件 = 按YAML元数据筛选（如 `WHERE chapter="第7章"`）

对AI导师说：
- "搜索知识库中所有关于 [[边界条件]] 的笔记"
- "列出第7章所有 ★★★ 级别的核心概念"
- "比较 [[镜像法]] 和 [[分离变量法]] 的优缺点"

## 重要提醒

- **所有知识以教科书为准**——笔记是帮助理解的，不是替代教科书的
- **费曼法的精髓是"自己的话复述"**——看完笔记后必须自己讲一遍
- **思考题先自己想**——不要直接看答案
- **MATLAB代码自己写**——提示词是引导，不是替代

## 费曼深度讲解

AI费曼导师的使用哲学：把AI当做一个"永不疲倦的费曼学习伙伴"。每次学习一个新概念后，打开AI对话，像教一个学生一样把你刚学的概念口头复述给AI——AI会扮演"学生"的角色追问"等等，你说电位是标量，那为什么电场是矢量？" 这种追问迫使你用最简单的语言解释清楚——这就是费曼学习法的精髓。

高效的AI使用策略：(1)先自学教科书原文和本笔记，形成初步理解；(2)打开AI对话，用自己理解后的大白话解释概念；(3)AI追问和挑战你的理解（"如果两个点电荷一个正一个负，中间的电场是零还是叠加？"）；(4)你回应AI的追问，暴露理解漏洞；(5)回到教科书和笔记，补充薄弱环节；(6)再次向AI复述——直到AI"无问题可问"为止。

AI与笔记系统的协同：AI对话本身不是"笔记"——它是"思维的脚手架"，用完可以拆。但对话中的重要发现（如"原来我一直把散度和旋度的符号搞反了"）应该记录到对应的原子笔记中，作为"常见误区"或"费曼检验"的新条目。AI是探索工具，Obsidian是沉淀工具——两者互补。

## Cherry Studio 知识库配置指南

### 嵌入模型设置
- 模型：Qwen3-Embedding-8B（MTEB多语言排行榜#1，得分70.58）
- 嵌入维度：4096（模型固定输出）
- 上下文/chunk大小：2048 tokens
- 重叠：256 tokens
- 原理：每篇笔记1500-3000 tokens被1-2个chunk完整覆盖，保留"概念→公式→推导"语义链

### 知识库导入
1. Cherry Studio → 知识库 → 添加知识库
2. 嵌入模型选择 Qwen3-Embedding-8B
3. 添加文件夹：选择 E:\obsidian_--git\电磁场与电磁波\
4. Cherry Studio自动扫描所有.md文件并向量化
5. 教科书原文文件夹也会被自动索引

### Cherry Studio 提示词模板
```
你是一位费曼学习法教育专家。请基于知识库中的内容，
用通俗易懂的语言解释 [概念]。
知识库中所有内容以教科书为准。

要求：
1. 先检索教科书原文（教科书原文/ 文件夹），确保概念正确
2. 用生活化类比建立直觉（参考笔记中的「类比与直觉」板块）
3. 指出常见误区（参考笔记中的「常见误区」板块）
4. 提出2-3个检验性问题（参考笔记中的「费曼检验」板块）
5. 如果用户理解有盲区，回溯到前置概念重新讲解
```
